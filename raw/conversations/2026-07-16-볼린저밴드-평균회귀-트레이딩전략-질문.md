## assistant — 2026-07-16T22:06:34.622Z

**볼린저 밴드(Bollinger Bands)**는 주식 기술적 분석에서 자주 쓰는 지표예요.

## 기본 개념
- **중간선**: 주가의 20일 이동평균
- **상단선**: 중간선 + (표준편차 × 2)
- **하단선**: 중간선 − (표준편차 × 2)

이 3개 선이 만드는 "띠" 모양이라고 해서 밴드(Band)라고 부릅니다.

## 투자 활용법
| 상황 | 신호 |
|------|------|
| 주가가 **상단선에 닿음** | 과매수(오버바이) → 팔 신호 |
| 주가가 **하단선에 닿음** | 과매도(오버셀) → 살 신호 |
| **밴드가 좁아짐** | 변동성 감소 → 조만간 큰 움직임 예상 |
| **밴드가 넓어짐** | 변동성 증가 → 추세 진행 중 |

## 간단한 예시
주가가 하단선 아래로 내려가면 → "지금 싸니까 살 때일 수도" 
주가가 상단선 위로 올라가면 → "지금 비싸니까 팔 때일 수도"

당신이 운영 중인 `dark-toss-api` 같은 트레이딩 봇에서도 이 지표를 활용해서 자동 매매 신호를 생성할 수 있어요. 다른 지표(RSI, MACD 등)와 함께 조합하면 더 정확한 판단이 가능합니다.

혹시 이 지표를 봇에 적용해보려고 하는 거라면, 특정 코드에 대해 물어봐 주세요.

## assistant — 2026-07-16T22:18:11.595Z

**평균회귀(Mean Reversion)**는 "주가는 결국 평균으로 돌아온다"는 투자 전략이에요.

## 기본 원리
주가가 너무 올라갔거나 너무 내려갔을 때, 시간이 지나면 다시 **평균값으로 돌아올 것**이라고 가정합니다.

```
과하게 올랐다 ↘️ 평균으로 회귀
평균 ←→ 
과하게 내렸다 ↗️ 평균으로 회귀
```

## 구체적인 예시
- 주가가 평소 10,000원인데 갑자기 12,000원까지 올랐다
  → "이건 비정상적으로 높다, 내려올 거야" → **팔 신호**
- 주가가 갑자기 8,000원까지 내렸다
  → "이건 비정상적으로 낮다, 올라올 거야" → **살 신호**

## 볼린저 밴드와의 관계
볼린저 밴드는 사실 **평균회귀 전략의 도구**에요:
- 상단선을 벗어나면 → 평균으로 돌아올 것 예상 (팔 신호)
- 하단선을 벗어나면 → 평균으로 돌아올 것 예상 (살 신호)

## 트레이딩 봇에 적용하면
```
1. 일정 기간 평균가 계산
2. 현재가가 평균에서 많이 벗어났는지 측정 (표준편차 이용)
3. 벗어난 만큼 → 평균 쪽으로 복귀할 거라 예상해서 매매
```

당신의 `dark-toss-api` 같은 봇에서 이 원칙을 적용하려면, 현물 변동성을 추적하다가 "이 정도면 반등할 만하다"는 지점에서 자동으로 매수/매도하게 설정할 수 있어요.

다만 **추세 시장에선 위험**해요 — 계속 올라만 가는 장에서는 "평균회귀 기다리다가" 손실이 계속 깊어질 수 있거든요.
