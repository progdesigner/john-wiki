Claude Code로 1시간 정도 코딩하면 API 종량제 기준 대략 **Opus 4.8은 $10~25, Sonnet 5는 $5~15, Haiku 4.5는 $2~5** 수준이고, 최상위인 Fable 5는 $20~50까지 올라갑니다. 아래는 현재 API 단가와 추정 근거입니다.

**모델별 API 단가 (1M 토큰당)**

| 모델 | 입력 | 출력 | 1시간 코딩 추정 |
|---|---|---|---|
| Claude Fable 5 | $10 | $50 | 약 $20~50 |
| Claude Opus 4.8 / 4.7 / 4.6 | $5 | $25 | 약 $10~25 |
| Claude Sonnet 5 | $3 / $15 (2026-08-31까지 프로모션 $2 / $10) | 좌동 | 약 $5~15 (프로모션가 $3~10) |
| Claude Sonnet 4.6 | $3 | $15 | 약 $5~15 |
| Claude Haiku 4.5 | $1 | $5 | 약 $2~5 |

추정의 가정은 이렇습니다. Claude Code는 프롬프트 캐싱을 강하게 쓰기 때문에 실제 비용의 대부분은 캐시 읽기(입력가의 약 0.1배)와 출력 토큰에서 나옵니다. "보통 강도"의 1시간 — 요청 약 40회, 캐시 읽기 누적 ~12M 토큰, 캐시 쓰기 ~2M(입력가의 1.25배), 신규 입력 ~0.4M, 출력 ~0.2M 토큰 — 으로 계산하면 Opus 4.8이 약 $25, Sonnet 5가 약 $15, Haiku가 약 $5가 나옵니다. 가벼운 사용(질문 몇 개, 소규모 수정)은 이 값의 1/3 정도, 대규모 리팩터링이나 에이전트를 오래 돌리는 헤비 사용은 2배 이상까지 갈 수 있어서 위 표는 범위로 적었습니다.

참고로 두 가지 변수가 있습니다. 첫째, 실제 비용은 컨텍스트 크기(큰 저장소일수록 캐시 읽기 증가)와 effort 설정에 크게 좌우되므로 같은 1시간이라도 편차가 큽니다. 둘째, API 종량제가 아니라 Claude Pro/Max 구독으로 Claude Code를 쓰면 시간당 한도 내에서는 추가 과금이 없어서, 매일 몇 시간씩 쓴다면 구독 쪽이 훨씬 저렴한 경우가 많습니다.
