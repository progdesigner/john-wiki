**원인**: api.lampas.io 앞의 nginx 가 요청 본문을 100MB 로 제한하고 있어, 그보다 큰 렌더 결과 mp4 를 올리면 413 이 납니다. 그 413 응답에는 CORS 헤더가 없어 브라우저에는 "Network Error"로만 보였습니다. 130MB 파일로 재현했고, 6MB 는 정상(401, 인증만 요구)이었습니다.

**수정**

- 렌더 결과를 API 를 거치지 않고 **브라우저에서 S3 로 직접** 올리도록 바꿨습니다. API 에 presigned URL 발급과 업로드 완료 확인 엔드포인트를 추가했고, 에디터는 발급 → S3 PUT → 확인 순서로 올립니다. nginx 와 ALB 제한을 모두 피하므로 수백 MB 도 올라갑니다. 확인 단계는 이 계정의 업로드 경로 키만 받아 남의 경로에 행을 만들 수 없습니다.
- 내보내기 오버레이에 업로드 진행률(%)이 표시됩니다.
- S3 버킷 CORS 의 PUT 허용 오리진에 `edit.lampas.io` 와 로컬 8458 을 추가했습니다. 지금까지 이 오리진이 빠져 있어서, 에디터의 원본 자동 백업(로컬 반입 원본을 S3 에 올리는 기능)도 조용히 실패하고 있었을 가능성이 큽니다. 이번 추가로 그것도 함께 동작합니다.
- 기존 multipart 업로드는 남겨 두어, presign 엔드포인트가 없는 구버전 API 를 만났을 때만 폴백합니다.
