게시 권한은 이미 들어가 있습니다. 권한 페이지에서 확인한 현재 상태입니다.

| 권한 | 상태 |
|---|---|
| `instagram_business_basic` | 테스트 준비 완료 |
| `instagram_business_content_publish` (게시물 게시) | 테스트 준비 완료 |
| `instagram_business_manage_messages` | 테스트 준비 완료 |

ai.dalar 계정의 권한 허용 화면에서도 "콘텐츠 액세스 및 게시"가 켜진 채로 허용됐으므로, 발급될 토큰에 게시 권한이 포함됩니다. 앱이 개발 모드여도 ai.dalar 는 Instagram 테스터라 검수 없이 게시 API 를 쓸 수 있습니다.

토큰은 아직 못 얻었고, 남은 건 **Instagram 앱 시크릿 코드**뿐입니다. 개발자 콘솔 탭 → "표시" → 비밀번호 확인 → 값을 드래그해 복사 → 이 채팅에 붙여넣어 주세요. 받는 즉시 code 교환 → 60일 장기 토큰 발급 → 계정 검증까지 자동으로 마무리합니다.
