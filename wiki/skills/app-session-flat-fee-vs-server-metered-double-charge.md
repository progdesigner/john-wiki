# 앱 고정요금 vs 서버 단가과금 중복차감

## 언제 쓰는가
"기능 A 사용 시 크레딧이 추가로 더 빠진다"는 제보를 받았을 때, 특히 앱(모바일/미니앱 등)이 자체적으로
고정 크레딧(flat fee)을 먼저 차감한 뒤 같은 요청이 내부적으로 호출하는 서버 엔드포인트가 모델별 단가로
한 번 더 차감하는 구조. [[lampas-studio]] 포토부스 앱(`lampas-app-photobooth`)이 "AI 사진 생성" 50크레딧을
선차감한 뒤 서버의 `POST /transforms/:key/run`이 모델 단가(nano-banana 80, gpt-image-2 10)를 또 차감한
사례에서 최초 확인.

## 절차 (단계별)
1. 제보된 "추가로 빠진다"는 크레딧 변화가 어느 두 차감 경로의 합인지부터 특정한다 — 앱 쪽 엔드포인트와
   서버 쪽 Transform/실행 엔드포인트를 각각 코드로 확인.
2. 두 경로가 같은 호출 체인(앱 요청 1번 → 서버 내부에서 재호출)인지 확인한다. 같은 체인이면 한쪽은
   의도(고정 요금제), 다른 쪽은 과금 누락(모델 단가 과금이 원래 일반 로그인 사용자용으로 설계됐는데
   앱 세션에도 그대로 적용됨)일 가능성이 높다.
3. 수정은 "앱 세션 토큰으로 들어온 요청"을 판별해 서버 쪽 모델 단가 차감을 건너뛰게 한다 — 일반
   로그인 사용자(web 등)의 과금은 그대로 유지해야 하므로 세션 종류 판정 로직을 별도 모듈로 분리한다
   (예: `app-credit-session.ts`). 이미지뿐 아니라 영상·이미지→영상처럼 같은 실행 엔드포인트를 타는
   다른 Transform 종류에도 동일 판정이 적용되는지 확인.
4. 과거 중복 차감분은 환불 대상이다 — [[bank-refund-invoice-reconciliation]]과 유사하게, 같은 사용자의
   "앱 고정요금" 차감 뒤 짧은 시간창(예: 30분) 안에 따라온 "서버 단가" 차감을 1:1로 짝지어 식별한다.
5. 환불은 [[credit-ledger-balance-pattern]] 원장에 조정(ADJUSTMENT) 행으로 남기고, 사유에 건수·추적ID를
   포함해 감사 가능하게 한다. 적용 후 같은 매칭 쿼리를 다시 돌려 대상이 0건인지 확인한다(재실행
   idempotent — [[signup-domain-abuse-rate-limit-and-reclaim]]이 썼던 것과 같은 검증 패턴).
6. 매칭되는 상대가 없는 단독 차감(예: 서버 단가 차감만 있고 짝이 되는 앱 차감이 없는 건)은 환불
   대상에서 제외한다 — 짝이 없다는 것은 다른 원인(수동 재시도 등)일 수 있어 섣불리 합치면 안 된다.
7. 수정 코드는 테스트·타입체크만으로 "실제 앱 요청에서 차감이 건너뛰어지는지"를 증명하지 않는다 —
   배포 전까지는 중복 차감이 계속되므로, 배포 완료를 명시적으로 확인하고 배포 시점까지 새로 쌓인
   추가 중복분을 한 번 더 환불 스크립트로 돌려야 한다.

## 주의사항 / 함정
- 배포 여부 확인 없이 "수정 완료"로 보고하면 사용자가 문제가 끝났다고 오인한다 — 로컬 수정과 운영
  배포는 별개임을 매번 명시한다.
- 앱 세션 판별을 너무 넓게 잡으면(예: 특정 User-Agent만 보고 판정) 일반 사용자의 과금까지 건너뛸 수
  있다 — 세션 토큰 종류 등 명확한 식별자로 좁혀야 한다.
- **커밋 전 배포가 사고로 먼저 일어날 수 있다**: 같은 작업 트리에서 다른 세션이 "작업 트리 확인+배포"를
  한 명령으로 이어 실행하면, 아직 git에 커밋되지 않은 로컬 수정이 **그 세션의 배포에 의도치 않게
  함께 실려 나갈 수 있다**. [[lampas-agent]] 2026-10-03 사례 — 이 스킬의 포토부스 수정이 바로 이
  경로로 운영 0.1.171에 먼저 배포되고, git 커밋은 그보다 한참 뒤("모든 코드 커밋해줘" 요청 시점,
  별도 커밋 `0f375722`)에야 이루어졌다. 되돌리면 중복 과금이 재발하므로 사고 배포 자체는 그대로
  두고, 커밋만 원래 세션 몫으로 분리해 나중에 정리하는 것이 합리적 대응이었다. **"배포됨"과
  "커밋됨"을 별개 사건으로 추적할 것** — 둘 중 하나만 확인하고 "완료"로 보고하면 틀릴 수 있다.
