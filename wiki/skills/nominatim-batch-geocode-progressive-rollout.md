# 지도 키 없이 대량 주소 지오코딩 + 단계적 배포

## 언제 쓰는가
수백 곳 이상의 주소 목록(엑셀·시트에서 받은 데이터 등, 좌표 없음)을 지도 위 핀으로 표시해야
하는데, 카카오·네이버 같은 유료/키 발급 필요 지도 API를 아직 쓸 수 없거나(키 인증 대기·미발급)
아예 안 쓰기로 한 경우. 지오코딩 정확도가 들쭉날쭉한 대량 주소 데이터를 다룰 때도 적용.

## 절차 (단계별)
1. **지도 자체는 OpenStreetMap** 사용 — 표시에 API 키가 필요 없다(카카오·네이버는 지도 렌더링에
   키·도메인 등록이 필요하지만 OSM 타일은 즉시 사용 가능).
2. **주소→좌표 변환은 Nominatim** — [이용 정책](https://operations.osmfoundation.org/policies/nominatim/)을
   지켜 **한 번에 한 요청, 초당 1회 이하**로 순차 처리. 배치로 무단 병렬 호출하면 차단당한다.
3. **결과를 저장(캐시)** — 같은 주소를 재요청하지 않도록 좌표 확인 결과를 데이터에 영구 반영.
   원본 소스(시트·엑셀)를 재수입해도 이미 확인된 좌표는 유지.
4. **신뢰도 필터로 오표시 방지** — Nominatim이 반환한 결과가 주소·건물번호까지 정확히 일치하는
   경우만 핀으로 표시한다. 도로 위 대략적 위치만 나오는 결과는 버리고 "위치 미확인"으로
   분류 — 틀린 위치에 핀을 찍는 것보다 미확인으로 남기는 게 낫다.
5. **미확인 항목은 목록에서 폴백 링크 제공** — 지도에 못 찍은 항목도 목록에서 카카오맵 등
   외부 지도 검색 링크로 연결해 사용자가 직접 찾아볼 수 있게 한다(기능 자체는 죽이지 않음).
6. **전체가 끝날 때까지 기다리지 않고 단계적으로 배포** — 대량 주소(수백~수천 건)를 초당 1회
   제한으로 처리하면 전체 완료까지 시간이 오래 걸린다. 확인된 좌표가 늘어날 때마다(예:
   130→200→275→350→394건) 중간 배포를 반복해 사용자가 진행 상황을 실시간으로 볼 수 있게 한다.

## 주의사항 / 함정
- **속도를 올리려고 병렬 요청하지 말 것** — Nominatim은 공용 무료 서비스라 정책 위반 시
  IP가 차단될 수 있다. 급하면 유료 지오코딩 API로 전환을 검토하되, 이 스킬은 "키 없이"가
  전제.
- **정확도와 커버리지는 트레이드오프** — 신뢰도 필터를 엄격히 하면(건물번호 일치만 인정)
  핀 개수가 줄지만 오표시 리스크도 줄어든다. 완화하면 커버리지는 늘지만 잘못된 위치에 핀이
  찍힐 수 있다 — 이 세션은 정확도 우선(오표시 방지)으로 판단.
- **지도 프로바이더 전환은 렌더링만 바꾸면 되지만, 지오코딩 결과는 재사용 가능** — 좌표
  자체는 프로바이더에 종속되지 않으므로, OSM→카카오/네이버로 나중에 바꿔도 이미 확인한
  좌표는 그대로 쓸 수 있다.
