# lampas-web-package ("Package", package.lampas.io)

`[[lampas-studio]]` 저장소(`lampas-system`)의 스포츠 클립 파이프라인 자매 앱. 완성된 릴스 영상을
등록하고 SNS 채널(릴스·인스타그램)에 게시하기 위한 제목·본문·해시태그를 준비하는 마지막 단계
앱이다. "새 패키지" 화면은 `https://package.lampas.io/new`.

이전까지는 다른 엔티티 페이지 안에서 "Package 앱(소속 미상)"으로만 언급됐다(`[[dalar-web-first]]`
"Package 연동" 절, `[[lampas-web-reels]]` "Package 연동" 절) — 이 페이지가 최초 정식 엔티티화이며,
`lampas-system` 저장소·`package.lampas.io` 소속임을 이 세션([[2026-09-20-lampas-package-pulse페르소나-릴스자동작성-톤선택]])에서
확인했다. `[[lampas-web-flow]]`의 6번째(마지막) Work 노드가 이 앱을 가리킨다.

## 관찰된 기능

### Pulse 페르소나 기반 릴스 제목·본문·해시태그 자동 작성 (2026-09-20)
- "새 패키지" 화면에서 `[[lampas-agent]]` Pulse가 만든 페르소나를 선택하면, 영상의 대표 장면
  3개를 참고해 릴스 제목·본문을 자동 생성. 장면을 읽을 수 없으면 사용자가 입력한 힌트로 대체.
- **해시태그 전용 입력 영역**, 최대 5개 제한 — 새 패키지 화면·릴스/인스타그램 편집 화면·저장
  API 세 곳 모두에 일관 적용.
- 생성 결과는 저장 후에도 릴스·인스타그램 편집 화면에 유지된다.

### 페르소나 우선순위 버그 — 하드코드 기본 프롬프트·타 영상 근거 혼입 (같은 세션)
- 페르소나 미선택 시 **"등장인물이 1인칭으로 말하는 일상 캡션"**을 강제하는 기본 프롬프트가
  있었고, 페르소나 선택 시에도 그 기준이 약해 페르소나 말투가 제대로 반영되지 않았음.
- 동시에 **현재 릴스와 무관한 다른 영상의 제목·댓글**이 프롬프트에 함께 전달돼 근거가 섞이는
  문제도 발견.
- 두 문제 모두 수정: 기본 1인칭 캡션 지시 제거(페르소나 설명·타겟만 기준), 상투적 감성 도입·
  맺음말 억제, 타 영상 근거 배제·확인 안 된 경기 상황 추측 금지. 절차는
  [[persona-prompt-default-override-audit]] 스킬로 일반화.

### 문체 톤 5종 선택 (같은 세션)
- 사용자가 원한 형식은 페르소나 서사가 아니라 **"전문 채널이 하이라이트를 소개하는 공지형
  게시글"**(예: "오늘 경기 주요 장면⚾ / [NEXT STREAMING] 샌디에이고 vs 콜로라도 …") — 이를
  기본 템플릿으로 삼고, 페르소나는 **채널의 관점·타겟**을 유지하는 역할로 재배치, 별도로
  선택 가능한 **톤(문체)** 을 그 위에 얹는 구조로 재설계.
- 톤 5종(기본값은 "전문 채널답게"):
  1. **전문 채널답게** — 공식 채널처럼 정돈된 소개 + 시청 안내 (기본값)
  2. **친근하게** — 팬에게 편하게 건네는 해요체
  3. **생동감 있게** — 짧고 활기찬 소개
  4. **담백하게** — 수식어를 줄인 간결한 안내
  5. **페르소나 말투 그대로** — 페르소나 원래 문체 유지
- 경기 일정 등 부가 정보는 별도 **"추가 안내"** 입력 필드에 넣을 때만 포함. 본문 구조는
  **콘텐츠 소개 → 시청 안내 → 선택한 추가 안내** 순.
- 실제 AI 검증(테스트용 야구 페르소나): "전문 채널답게" → "MLB 주요 경기 하이라이트를
  간추렸습니다. 핵심 장면을 릴스에서 확인해 보세요", "친근하게" → "놓친 하이라이트
  있으신가요? ⚾" — 둘 다 입력한 방송 일정·줄바꿈 유지.

### 배포 이력
- 1단계(자동 작성 구현): 웹 테스트 23개 → 웹+API 배포.
- 2단계(페르소나 우선순위 수정): API 테스트 961개 → API만 재배포(웹 변경 없음).
- 3단계(톤 5종): API 테스트 968개 → 웹+API 배포, 실제 서비스 반영 확인.
