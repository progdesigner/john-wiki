# lampas-web-tools ("Tools", `tools.lampas.io`)

`[[lampas-studio]]` 저장소(`lampas-system`)의 앱. 13개 AI 생성 기능(이미지·오디오·비디오 등)을 모아
제공하는 도구 모음 웹. 2026-09-25 세션([[2026-09-25-copy스크롤-fixs삭제-tools모델표시-영상재생버그]])에서
처음 위키에 노출됨 — 저장소 루트 `AGENTS.md`(Lampas/Dalar/Talk 3라인 앱 목록)에는 등장하지 않아,
`[[lampas-agent]]`·`[[lampas-web-copy]]` 등 스포츠 클립 파이프라인과 마찬가지로 **AGENTS.md 목록과
실제 앱 부분집합이 다르다**는 기존 관찰(→ `[[lampas-studio]]` "스포츠 클립 파이프라인" 절)을 한 번 더
확인시켜주는 세 번째 사례.

## 기능·모델
- **13개 기능**에 목록·상세 화면에서 실제 실행 모델을 표시(여러 모델을 단계적으로 쓰는 기능은 단계별
  표시), 2026-09-25 세션에서 추가·배포(v0.1.3).
- 영상 생성에 **Kling**(`kwaivgi/kling-*`, Atlas Cloud 경유 추정 — 이 위키에 Kling 모델 최초 노출)을
  사용 확인. 콘텐츠 심사 거절 시 응답에 `Failure to pass the risk control system`만 오고 구체적 사유는
  없음 — 클라이언트에서 거절 자체를 해제할 수는 없어, 거절 사유를 사라지는 토스트 대신 **결과 영역에
  유지**하고 실패 상태·재시도·[[lampas-agent]] Fixs 보고 처리를 개선(v0.1.3).
- **`music-gen` 툴은 minimax 2.6 고정** — 자매 앱 [[lampas-web-music]]이 2026-09-22 3.0으로 업그레이드
  됐을 때 요청 범위가 music.lampas.io로 한정돼 이 툴은 손대지 않음, 버전 불일치 상태로 남아 있음.
- **`talking-photo.ts`**(`kwaivgi/kling-v2.6-std/avatar` 호출) — 2026-09-13 세션(→
  [[lampas-web-scenario]])이 이 파일을 저장소 전체에서 **아바타/립싱크 계열 모델의 유일한 실제 요청
  body 근거**로 확인함: `{ image, audio }`만 보내고 `prompt` 필드는 없음(가격 카탈로그는 이런 스키마
  정보를 기록하지 않음, → [[atlas-cloud]]).

## 알려진 버그·수정 이력 (2026-09-25, 한 세션 내 4단계)
1. **업로드 응답 인식 실패**(v0.1.2) — 서버가 반환하는 `download_url` 필드 형식을 프론트가 인식 못해
   업로드 성공을 실패로 오판. 오디오·비디오 입력도 같은 업로드 코드를 공유해 동일 수정 적용.
2. **잘못된 재생 주소**(v0.1.4) — 영상 생성은 성공했으나 존재하지 않는 `/v1/ai/media`로 요청해 404.
   원본 주소 재생으로 수정 + 기존 생성 결과 복원 표시.
3. **재발**(같은 세션, 버전 미명시) — v0.1.4가 기존 저장 영상 재생은 고쳤지만 **새로 생성하는 영상**의
   재생 경로는 여전히 문제였음. 사용자가 "S3 업로드해서 보이게 하고 API 프록시로 보이게 하지 말라"고
   아키텍처를 직접 지정.
4. **S3/CloudFront 직접재생 전환** — 근본 원인 3건: ① 신규 생성 영상은 S3·CloudFront에 정상 저장돼
   있었으나 재생 실패 로그가 계속 옛 `/v1/ai/media` 요청을 가리킴(프론트 캐시 의심), ② 일부 임시 영상
   주소가 S3 저장 대상에서 누락, ③ S3 저장 실패 시 임시 주소를 그대로 반환하던 폴백이 실패를 숨김.
   저장 완료 주소만 반환하도록 수정, 옛 프록시 형식 저장 기록을 파일 주소로 복원, HTML 캐시 무효화.
   **⚠️ 세션 종료 시점까지 새로 생성한 영상이 실제로 화면에 보이는지는 미확인** — v0.1.4도 "확인
   완료"로 배포됐다가 재발한 전례가 있어, 다음 세션에서 재검증 필요.

## 오류 수집 (Fixs 연동)
- 이 앱 재조사 중 **공통 Fixs 수집기가 HTTP 500 이상만 감지**해 400 오류(Kling 거절)를 놓치고
  있었음이 드러남 → 400대 응답·네트워크 오류·콘솔 오류까지 수집하도록 확장, 웹 프론트 36개(33개 재배포
  + 3개 소스만 반영) + 토스 미니앱 2개(소스만)에 반영. 상세는 [[lampas-agent]] Fixs 절과
  [[2026-09-25-copy스크롤-fixs삭제-tools모델표시-영상재생버그]] 참고.
