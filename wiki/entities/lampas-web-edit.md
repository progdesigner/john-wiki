# lampas-web-edit ("Edit", edit.lampas.io)

`[[lampas-studio]]` 저장소(`lampas-system`)의 스포츠 클립 파이프라인 자매 앱. 클립을 실제로
편집(자막·텍스트 오버레이·이미지·트랙 배치)해 최종 영상으로 렌더링하는 웹 에디터. `[[lampas-web-flow]]`의
5번째 노드(Edit)가 이 앱을 가리킨다. [[2026-09-19-lampas-edit-자막-템플릿-대량기능개발]] 세션에서
이 위키에 처음 상세 노출됨(버전 0.1.17→0.1.43).

## 원칙: 미리보기·렌더 공용 함수
이 앱의 반복되는 설계 원칙 — 자막 그리기(`drawSubtitle`), 큐 선택(`activeCueAt`), 자막 세로
정렬·위치 계산, 텍스트 행간, 레이어 스택 합성을 **미리보기 캔버스와 최종 렌더가 항상 같은 함수를
공유**한다. 그래서 기능을 하나 추가하면 미리보기·결과물이 자동으로 일치하고, 버그도 두 곳에 동시
나타나거나 동시에 고쳐진다(예: 0.1.28 자막 사라짐 버그가 미리보기·렌더 모두에서 동시 발생·동시 수정).

## 자막(Subtitle) 시스템
- **양옆 여백**: `subtitles.sideMargin`(캔버스 폭 대비 0~25%, 기본 5%). 실측 폭(`measureText`) 기준
  어절 단위 줄바꿈으로 교체(기존 "글자당 0.62em" 추정이 한글에서 잘림의 근본원인). 여백보다 큰
  단일 단어는 폰트 비례 축소.
- **세로 위치·정렬 기준**: 프리셋(하단82%·중앙50%·상단14%)은 1회 초기화용, 이후 미리보기 드래그
  또는 슬라이더(5~95%)로 자유 조정 + 가운데 스냅. **세로 기준**(위/가운데/아래) 칩으로 줄 수가
  늘어날 때 어느 방향으로 자랄지 결정.
- **단어 강조(karaoke)**: ASR 단어 타임스탬프 기반. 텍스트를 수정하면 원본 단어와 diff해 같은
  토큰은 원래 시각 유지, 새 단어는 이웃 단어 사이 시간을 글자 수 비례로 분배(0초 방지). 수동으로
  추가한 큐(타임스탬프 없음)는 어절 글자 수 비례로 발화 타이밍을 합성해서 강조 가능(2어절 이상 조건).
- **"다음 자막까지 유지"** 체크박스: 큐 종료 후 다음 큐 시작(또는 클립 끝)까지 화면에 남김.
- **한국어 번역**: 영어 발화 자막을 AI 게이트웨이로 40개씩 배치 번역, 원문은 큐에 보관해 되돌리기
  가능, 큐 시각/단어 타임스탬프는 그대로 둠.
- **타이포**: 투명도·자간·행간(기본120%, 80~250%)·장평(scaleX)·기울임 — 텍스트 오버레이와 값 범위
  공유, 레이아웃 템플릿에도 포함되어 함께 저장·적용됨.

## 큐(자막 구간) 편집
- **합치기**: 마지막 제외 모든 큐에 "↓ 아래와 합치기" — 구간·텍스트·단어 타임스탬프를 순서대로 병합.
- **위/아래에 추가**: 인접 빈 시간에 최대 2초 새 큐 삽입, 빈 시간 없으면 해당 큐를 반으로 분할(0.2초
  미만이면 무동작).
- **textarea + 강제 줄바꿈**: Enter로 줄 추가(최대 6줄), 줄바꿈 위치가 자막에 그대로 반영.

## 레이어/트랙
- 영상·이미지·텍스트가 **하나의 스택**으로 합쳐져 종류 무관하게 순서 변경 가능(▲▼). 자막은 가장
  위 클립 레이어 바로 위에 그려져, 텍스트 레이어를 그 위/아래로 옮기면 자막을 덮거나 가려짐.
- 트랙 이름은 **클릭 즉시 편집**(더블클릭 아님), 순서를 바꿔도 이름은 내부 번호 기준 유지(한 번
  순서기준 번호매김으로 바꿨다가 사용자 요청으로 롤백, 0.1.33).

## 미리보기 상호작용
- 자막·영상 팬 모두 드래그로 위치 조정 가능. 정중앙 근처에서 픽셀 거리(캔버스 짧은 변의 2%) 기준
  스냅 + 점선 가이드. 드래그 우선순위: 꾸미기 텍스트 → 자막 → 선택 클립 팬.

## 레이아웃 템플릿
- **저장 항목**: 캔버스 비율, 트랙 스택 순서, 영상별 맞춤(fit/scale/pan), 이미지별 위치·크기·투명도·
  레이어, 텍스트별 위치·크기·폰트·자간·장평·기울임·레이어+기본 문구, (0.1.30~) 첫 영상 클립의 자막
  스타일 전체.
- **적용**: 비율·트랙 순서 맞춤, 이미지는 파일 지문 일치 시 위치만 이동·없으면 새로 추가, 텍스트는
  레이어·시작 순으로 짝지어 스타일만 이식(문구는 유지, 템플릿이 더 많으면 새 텍스트 생성).
  텍스트마다 **템플릿 슬롯 키**를 붙여 트랙 이동 후에도 같은 슬롯으로 복귀.
- **계정 종속화**(0.1.38, API `/v1/layout-templates`, 테이블 `layout_templates`): 로그인 시
  서버 목록이 진실 소스, 로컬 전용 템플릿은 로그인 시 1회 자동 업로드. 로그아웃 상태는 로컬에만
  저장되고 "(이 브라우저만)" 표시.
- **다른 계정으로 보내기**(0.1.41): 이메일로 대상 lampas 계정 가입 여부 확인 후 그 계정 소유로
  복제(원본 유지, 복제본에 발신자·시각 기록). 로컬 전용(미업로드) 템플릿은 보낼 수 없음.
- **이미지 슬롯 fingerprint/url 이원 구조**: 로컬 fingerprint 우선, 없으면 템플릿 `url`(S3/CDN),
  그래도 없으면 계정 백업에서 조회 → [[template-image-slot-fingerprint-vs-url]] (이 앱의 0.1.42가
  `url` 필드의 최초 구현 지점, 상세는 그 스킬 문서 참고).

### `layout_templates` 테이블 (lampas MySQL DB, Prisma 모델 `LayoutTemplate`)
`id`(VARCHAR64, 클라이언트 `tpl-...`) · `userId`(FK) · `name` · `payload`(JSON, 템플릿 전체) ·
`createdAt`/`updatedAt`/`deletedAt`(소프트삭제). DDL: `apps/lampas-api/prisma/manual/
2026-09-20-layout-templates.sql`. 브라우저 로컬 캐시 키: `lampas-edit.layoutTemplates.v1`.

## 내보내기(Export)
- **"파일 다운로드" 토글**(0.1.40): 끄면 갤러리 업로드만, 자동 다운로드 생략(단, webm 프리셋·
  로그아웃·업로드 실패 시에는 토글 무관 항상 다운로드 — 결과가 사라지지 않도록).
- **갤러리 업로드가 브라우저→S3 직접(presigned PUT)으로 전환**(0.1.43): 이전엔 API를 거쳐 올리다
  nginx 100MB 본문 제한(413, CORS 헤더 없어 브라우저에는 "Network Error"로만 보임)에 걸림 →
  [[proxy-body-limit-413-appears-as-network-error]]. 이 과정에서 S3 버킷 CORS PUT 허용 오리진에
  `edit.lampas.io`가 원래 빠져 있어 **원본 자동 백업 기능도 조용히 실패하던 것**을 함께 발견·수정.

## 배포 인프라
- 타임라인 눈금자(룰러) sticky 고정을 두 번 시도(0.1.27 실패→0.1.29 성공) — 1차 실패 원인은
  sticky 기준 스크롤 조상이 가로 스크롤 컨테이너였던 것; 2차는 눈금자를 세로 스크롤 영역 밖 별도
  고정 행으로 분리해 해결.
- 미리보기·렌더가 자막을 그릴 클립을 고르는 로직 결함(자막 켜진 첫 클립만 선택 → 큐 없는 이미지가
  선택되면 그 아래 영상 자막이 사라짐)을 0.1.28에서 수정.
- Reels가 편집 세션 생성 요청에 브랜드킷 목록 응답(`isDefault`·`createdAt`·`updatedAt` 포함)을
  그대로 넣어 서버 DTO 검증에 걸리던 오류를 0.1.30(+Reels 0.1.24)에서 스냅샷 필드만 남기도록 수정
  → [[lampas-web-reels]].

## 배포 방식
S3 업로드 + CloudFront 무효화(정적 SPA), API는 PM2. 배포 전 매번 `web-edit` 타입체크+전체
테스트(500~580여 개)를 통과시키는 패턴이 일관됨.
