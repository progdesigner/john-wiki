# lampas-web-edit ("Edit", edit.lampas.io)

`[[lampas-studio]]` 저장소(`lampas-system`)의 스포츠 클립 파이프라인 자매 앱. 클립을 실제로
편집(자막·텍스트 오버레이·이미지·트랙 배치)해 최종 영상으로 렌더링하는 웹 에디터. `[[lampas-web-flow]]`의
5번째 노드(Edit)가 이 앱을 가리킨다.

**시점 정정(2026-09-26 추가 ingest, 두 번째 정정)**: 이 페이지는 처음 "[[2026-09-19-lampas-edit-자막-템플릿-대량기능개발]]
세션에서 위키에 처음 상세 노출됨(0.1.17→0.1.43)"으로 기록했으나, 그보다 **6일 앞선**
[[2026-09-13-lampas-edit-이미지트랙-텍스트효과-원본백업-구현]] 세션(그날의 다른 09-13 세션들 —
CS·시나리오·dalar-web-first — 보다도 이른 06:10Z 시작)이 실제 더 이른 관찰 지점이다. 세션 시작
당시 이 앱은 이미 완전히 영상 전용(mediabunny 디코딩)이었으므로 절대적 기원(0.1.2 이전 히스토리)은
이 소스로도 확인 불가하지만, **이미지 미디어/이미지 트랙/트랙 순서 스왑, 텍스트 자간·장평·기울임,
로그인 계정 원본 자동 S3 백업(`EditSessionAsset`)의 원출처는 이 09-13 세션**이다(버전 0.1.2→0.1.11
부근). 아래 각 절에 도입 시점을 정확히 표기한다. 또한 아래 "Auto Reframe"·"브랜드 킷 적용"·
"자막 생성 청크 분할" 절은 09-13보다는 늦지만 09-19보다는 하루 빠른
[[2026-09-18-lampas-clip-intelligence-brand-kit-대량구현]] 세션에서 구현된 것 — 정확한 도입 순서는

## 이미지 미디어·트랙·텍스트 효과·원본 백업 최초 구현 (2026-09-13)
- **이미지를 미디어로 추가**(0.1.2→0.1.3): `ReelClip`/`LibraryItem`에 `kind:'video'|'image'`,
  `probeImage`가 이미지 파일을 프로브(너비/높이, 기본 표시 5초), 트림은 이미지에 한해 원본 길이
  상한 없음. 미리보기(`<img>`)·렌더(`createImageBitmap` 정지 프레임)를 영상과 별도 경로로 처리.
- **이미지 트랙 + 트랙 행 전체 스왑**(0.1.2→0.1.3): `TrackType:'image'` 신설. 영상·이미지 트랙을
  아우르는 `trackOrder`(z-order) 개념을 도입해 트랙 헤더 ▲▼ 버튼으로 트랙 전체(그 안 모든 클립)를
  인접 트랙과 한 번에 교체 — 오디오 트랙엔 이 버튼 없음. (텍스트 오버레이까지 같은 스택에 합쳐진
  것은 09-19 세션 0.1.25, 아래 "레이어/트랙" 절 참고.)
- **이미지 위치/크기를 텍스트 오버레이처럼**(0.1.3→0.1.4): 이미지가 영상의 Cover/Contain+팬 모델
  대신 캔버스 중심 x/y 드래그 + 휠 스케일(최소 5%)로 다뤄지도록 변경 — 스티커/로고처럼 작게도 배치
  가능해짐.
- **투명도(opacity)**(0.1.4→0.1.5): 이미지·텍스트 오버레이 둘 다에 슬라이더 추가. (자막 큐에 같은
  값 범위가 확장된 것은 09-19 세션 0.1.32.)
- **텍스트 자간·장평·기울임**(0.1.9→0.1.11): 텍스트 오버레이에 자간(letter-spacing)·장평(가로폭
  scaleX), 이어서 기울기(skewX, 체크박스로 12° 고정)를 추가한 최초 구현 — 09-19 세션 0.1.32의
  "자막 타이포(자간·행간·장평·기울임)"가 이 값 범위를 그대로 재사용한다.
- **이미지 스케일업 좌측 쏠림 버그**(0.1.5→0.1.6): Tailwind Preflight의 `img{max-width:100%}`가
  인라인 `width`와 별개로 계속 적용돼, 스케일 100% 초과 시 렌더 폭만 눌리고 위치 계산은 안 눌린
  폭 기준이라 어긋난 것 — 인라인 `maxWidth:'none'`으로 수정. 최종 렌더(canvas 2D)는 이 버그의
  영향을 받지 않았음(미리보기 전용 버그). → [[tailwind-preflight-img-maxwidth-overrides-inline-scale]]
- **클립 드래그로 트랙 간 세로 이동**(0.1.6→0.1.7): 기존엔 가로(시간) 드래그만 됐고 트랙 이동은
  우클릭 메뉴로만 가능했던 것을, 드래그 중 같은 종류(영상↔영상, 이미지↔이미지) 트랙 행 위로 커서가
  올라가면 실시간으로 옮기도록 수정.
- **하단 트랙 스크롤 안 보임 버그**(0.1.7→0.1.8): flex stretch 기본값 + 오른쪽 칸 `overflow-y-hidden`
  조합이 넘치는 트랙(이미지 3, 4…)을 그냥 잘라버린 것 — 두 칸 모두 내용 높이만큼 자연 확장시키고
  세로 스크롤을 바깥 컨테이너 하나가 전담하도록 수정.
- **화면 맞춤 스케일 슬라이더 step 5%→1%**(0.1.8→0.1.9).
- **로그인 계정 원본 자동 S3 백업**(버전 미상, 같은 세션 후속): "다른 컴퓨터에서 세션을 열면 로컬
  반입 파일이 파일 없음으로 뜬다"는 문제를 근본 해결 — fingerprint(`size-lastModified-name`) 기준
  사용자당 1회 S3 백업, 세션 열 때 없으면 자동 재다운로드. `lampas-api`에 `EditSessionAsset` 테이블
  + presign/confirm/조회 3개 엔드포인트 신설(`scenario-sessions`의 기존 S3 영속화 패턴 재사용).
  절차 일반화 → [[local-asset-fingerprint-s3-backup-recovery]]. 이 백업 인프라가 이후 09-19 세션
  0.1.42의 템플릿 이미지 `url` 폴백 체인 3단계("로컬→템플릿url→로그인계정 원본 자동 백업") 중
  마지막 단계로 재사용됨 → [[template-image-slot-fingerprint-vs-url]].
- **미디어 추가 시 소스/훅점수 필터 — 조사만 하고 미구현**: 소스 필터(`GET /clips/sources` +

  없어(정렬만 지원) 클라이언트 후필터(`lampas-web-reels`와 동일 패턴) 또는 서버 필터 신설 중 선택이
  필요하다는 조사 결과만 남기고 실제 구현은 이 세션에서 착수되지 않음 — 후속 세션에서 재확인 필요.
- 세션 전체 → [[2026-09-13-lampas-edit-이미지트랙-텍스트효과-원본백업-구현]]

## Auto Reframe(9:16 자동 리프레임) — 모션 무게중심 근사 (2026-09-18 도입, 이후 2회 개선)
인스펙터 "화면 맞춤" 탭의 "피사체 따라 자동 팬" 버튼. 클립 구간을 4fps로 샘플링해 프레임 간 움직임의
무게중심을 구하고, 세로 캔버스에서 보이는 비율 기준으로 그 중심이 화면 가운데 오도록 **팬 키프레임**을
생성한다. **얼굴 검출이 아니라 모션 무게중심 근사**라 스포츠·인물 이동 컷에 맞고, 정적 컷은 팬할
근거가 없어 중앙 고정으로 남는다. 미리보기와 최종 렌더가 같은 보간 함수를 공유.
- **키프레임 수동 조정**(후속 요청): 인스펙터에 키프레임 목록이 추가돼 좌↔우 슬라이더로 위치 조정,
  ✕로 삭제, "+ 현재 위치"로 플레이헤드 시각에 키프레임 추가. 미리보기 드래그 시 예전엔 키프레임
  전체가 해제됐으나, **현재 시각의 키프레임만 갱신**하도록 변경(키프레임이 없는 클립은 기존대로 고정
  팬 이동).
- **분석 시 fit/scale 유지**(후속 요청): 처음엔 분석이 Cover로 강제 전환했으나, "스케일링은 그대로
  둔 채 분석하게" 요청으로 현재 설정된 Cover/Contain과 스케일을 유지한 채 그 상태에서 보이는 창
  기준으로만 키프레임을 생성하도록 수정. 전부 보이는 상태(팬 여지 없음)면 안내만 표시.
- **Contain 모드 팬 버그 수정**: Contain에서 가로 영상은 캔버스 폭에 딱 맞아 팬 범위가 0이었고,
  스케일로 넘친 부분엔 팬이 전혀 걸리지 않았다 — 릴스 기본 레이아웃(Contain + 1:1 확대)이 정확히
  이 상태라 실사용에서 좌우 이동이 막혀 있었다. `clipDrawRect`를 고쳐 스케일 전 넘침이 없는 축에서는
  스케일 후 넘친 만큼에 팬을 적용하도록 수정(팬 0.5=가운데는 두 방식 동일이라 기존 프로젝트 렌더
  결과는 불변). 미리보기 `<video>`도 CSS `objectPosition` 대신 렌더와 동일한 dest-rect 직접 배치로
  전환해 미리보기·렌더가 완전히 같은 공식을 쓰게 됨.

## 브랜드 킷 적용 (2026-09-18 도입)
`lampas-api`의 신규 `brand-kits` 모듈(로고·폰트·자막 스타일·팔레트·CTA·워터마크를 계정 프리셋으로
저장)이 편집 세션에 스냅샷으로 전달되면, 시드 직후 자막 스타일·워터마크·CTA·로고 레이어가 자동
적용된다. 홈에 브랜드 킷 관리 패널 추가. Reels가 세션 생성 시 브랜드킷 **목록 응답 객체를 그대로**
넘겨 `isDefault`/`createdAt`/`updatedAt` 같은 DTO가 허용하지 않는 필드 때문에 검증 오류가 났던 것은
0.1.30(+Reels 0.1.24)에서 스냅샷 필드만 남기도록 수정됨(아래 "배포 인프라" 절 기존 기록).

## 자막 생성(ASR) 청크 분할 수정 — 긴 구간 전사 중간 끊김 (2026-09-18)
"자막 생성 시 모든 내용이 전사되지 않는다" 제보. 원인: 트림 구간 전체를 48kHz 스테레오 WAV 한 파일로
통째 ASR에 보냈는데(`[[lampas-agent]]` 인제스트는 16kHz 모노로 줄여 600초 단위 분할 전송하는 반면
에디터만 예외), 구간이 길면 모델이 앞부분만 전사하고 뒤를 버렸다. 단어 타임스탬프도 클립 기준 큐로
옮길 때 누락되고 있었다. 수정: 트림 구간을 300초 청크로 나눠 청크마다 오디오 추출→16kHz 모노
리샘플→WAV 업로드→전사(빈 결과/실패 시 소음 보정 폴백 모델)→청크 시작 시각 보정 후 이어붙임, 단어
타임스탬프 보존. 리샘플로 업로드 크기 약 1/6 감소. 일반화된 절차 → [[asr-long-audio-silent-truncation]].

## 원칙: 미리보기·렌더 공용 함수
이 앱의 반복되는 설계 원칙 — 자막 그리기(`drawSubtitle`), 큐 선택(`activeCueAt`), 자막 세로
정렬·위치 계산, 텍스트 행간, 레이어 스택 합성을 **미리보기 캔버스와 최종 렌더가 항상 같은 함수를
공유**한다. 그래서 기능을 하나 추가하면 미리보기·결과물이 자동으로 일치하고, 버그도 두 곳에 동시
나타나거나 동시에 고쳐진다(예: 0.1.28 자막 사라짐 버그가 미리보기·렌더 모두에서 동시 발생·동시 수정).

## 자막(Subtitle) 시스템
- **양옆 여백**: `subtitles.sideMargin`(캔버스 폭 대비 0~25%, 기본 5%). 실측 폭(`measureText`) 기준
  어절 단위 줄바꿈으로 교체(기존 "글자당 0.62em" 추정이 한글에서 잘림의 근본원인). 여백보다 큰
  단일 단어는 폰트 비례 축소.
- **세로 위치·정렬 기준**: 프리셋(하단82%·중앙50%·상단14%)은 1회 초기화용, 이후 미리보기 드래그
  또는 슬라이더(5~95%)로 자유 조정 + 가운데 스냅. **세로 기준**(위/가운데/아래) 칩으로 줄 수가
  늘어날 때 어느 방향으로 자랄지 결정.
- **단어 강조(karaoke)**: ASR 단어 타임스탬프 기반. 텍스트를 수정하면 원본 단어와 diff해 같은
  토큰은 원래 시각 유지, 새 단어는 이웃 단어 사이 시간을 글자 수 비례로 분배(0초 방지). 수동으로
  추가한 큐(타임스탬프 없음)는 어절 글자 수 비례로 발화 타이밍을 합성해서 강조 가능(2어절 이상 조건).
- **"다음 자막까지 유지"** 체크박스: 큐 종료 후 다음 큐 시작(또는 클립 끝)까지 화면에 남김.
- **한국어 번역**: 영어 발화 자막을 AI 게이트웨이로 40개씩 배치 번역, 원문은 큐에 보관해 되돌리기
  가능, 큐 시각/단어 타임스탬프는 그대로 둠.
- **타이포**: 투명도·자간·행간(기본120%, 80~250%)·장평(scaleX)·기울임 — 텍스트 오버레이와 값 범위
  공유(자간·장평·기울임의 원출처는 09-13 세션의 텍스트 오버레이 구현, 위 "이미지 미디어·트랙·텍스트
  효과·원본 백업 최초 구현" 절 참고), 레이아웃 템플릿에도 포함되어 함께 저장·적용됨.

## 큐(자막 구간) 편집
- **합치기**: 마지막 제외 모든 큐에 "↓ 아래와 합치기" — 구간·텍스트·단어 타임스탬프를 순서대로 병합.
- **위/아래에 추가**: 인접 빈 시간에 최대 2초 새 큐 삽입, 빈 시간 없으면 해당 큐를 반으로 분할(0.2초
  미만이면 무동작).
- **textarea + 강제 줄바꿈**: Enter로 줄 추가(최대 6줄), 줄바꿈 위치가 자막에 그대로 반영.

## 레이어/트랙
- 영상·이미지·텍스트가 **하나의 스택**으로 합쳐져 종류 무관하게 순서 변경 가능(▲▼). 자막은 가장
  위 클립 레이어 바로 위에 그려져, 텍스트 레이어를 그 위/아래로 옮기면 자막을 덮거나 가려짐.
  **▲▼ 트랙 전체 스왑 자체는 09-13 세션에서 영상·이미지 트랙만 대상으로 처음 구현**됐고(오디오
  트랙 제외는 그때부터 동일), 텍스트까지 같은 스택에 합쳐진 것은 09-19 세션 0.1.25.
- 트랙 이름은 **클릭 즉시 편집**(더블클릭 아님), 순서를 바꿔도 이름은 내부 번호 기준 유지(한 번
  순서기준 번호매김으로 바꿨다가 사용자 요청으로 롤백, 0.1.33).

## 미리보기 상호작용
- 자막·영상 팬 모두 드래그로 위치 조정 가능. 정중앙 근처에서 픽셀 거리(캔버스 짧은 변의 2%) 기준
  스냅 + 점선 가이드. 드래그 우선순위: 꾸미기 텍스트 → 자막 → 선택 클립 팬.

## 레이아웃 템플릿
- **저장 항목**: 캔버스 비율, 트랙 스택 순서, 영상별 맞춤(fit/scale/pan), 이미지별 위치·크기·투명도·
  레이어, 텍스트별 위치·크기·폰트·자간·장평·기울임·레이어+기본 문구, (0.1.30~) 첫 영상 클립의 자막
  스타일 전체.
- **적용**: 비율·트랙 순서 맞춤, 이미지는 파일 지문 일치 시 위치만 이동·없으면 새로 추가, 텍스트는
  레이어·시작 순으로 짝지어 스타일만 이식(문구는 유지, 템플릿이 더 많으면 새 텍스트 생성).
  텍스트마다 **템플릿 슬롯 키**를 붙여 트랙 이동 후에도 같은 슬롯으로 복귀.
- **계정 종속화**(0.1.38, API `/v1/layout-templates`, 테이블 `layout_templates`): 로그인 시
  서버 목록이 진실 소스, 로컬 전용 템플릿은 로그인 시 1회 자동 업로드. 로그아웃 상태는 로컬에만
  저장되고 "(이 브라우저만)" 표시.
- **다른 계정으로 보내기**(0.1.41): 이메일로 대상 lampas 계정 가입 여부 확인 후 그 계정 소유로
  복제(원본 유지, 복제본에 발신자·시각 기록). 로컬 전용(미업로드) 템플릿은 보낼 수 없음.
- **이미지 슬롯 fingerprint/url 이원 구조**: 로컬 fingerprint 우선, 없으면 템플릿 `url`(S3/CDN),
  그래도 없으면 계정 백업에서 조회 → [[template-image-slot-fingerprint-vs-url]] (이 앱의 0.1.42가
  `url` 필드의 최초 구현 지점, 상세는 그 스킬 문서 참고).

### `layout_templates` 테이블 (lampas MySQL DB, Prisma 모델 `LayoutTemplate`)
`id`(VARCHAR64, 클라이언트 `tpl-...`) · `userId`(FK) · `name` · `payload`(JSON, 템플릿 전체) ·
`createdAt`/`updatedAt`/`deletedAt`(소프트삭제). DDL: `apps/lampas-api/prisma/manual/
2026-09-20-layout-templates.sql`. 브라우저 로컬 캐시 키: `lampas-edit.layoutTemplates.v1`.

## 내보내기(Export)
- **"파일 다운로드" 토글**(0.1.40): 끄면 갤러리 업로드만, 자동 다운로드 생략(단, webm 프리셋·
  로그아웃·업로드 실패 시에는 토글 무관 항상 다운로드 — 결과가 사라지지 않도록).
- **갤러리 업로드가 브라우저→S3 직접(presigned PUT)으로 전환**(0.1.43): 이전엔 API를 거쳐 올리다
  nginx 100MB 본문 제한(413, CORS 헤더 없어 브라우저에는 "Network Error"로만 보임)에 걸림 →
  [[proxy-body-limit-413-appears-as-network-error]]. 이 과정에서 S3 버킷 CORS PUT 허용 오리진에
  `edit.lampas.io`가 원래 빠져 있어 **원본 자동 백업 기능도 조용히 실패하던 것**을 함께 발견·수정.

## 배포 인프라
- 타임라인 눈금자(룰러) sticky 고정을 두 번 시도(0.1.27 실패→0.1.29 성공) — 1차 실패 원인은
  sticky 기준 스크롤 조상이 가로 스크롤 컨테이너였던 것; 2차는 눈금자를 세로 스크롤 영역 밖 별도
  고정 행으로 분리해 해결.
- 미리보기·렌더가 자막을 그릴 클립을 고르는 로직 결함(자막 켜진 첫 클립만 선택 → 큐 없는 이미지가
  선택되면 그 아래 영상 자막이 사라짐)을 0.1.28에서 수정.
- Reels가 편집 세션 생성 요청에 브랜드킷 목록 응답(`isDefault`·`createdAt`·`updatedAt` 포함)을
  그대로 넣어 서버 DTO 검증에 걸리던 오류를 0.1.30(+Reels 0.1.24)에서 스냅샷 필드만 남기도록 수정
  → [[lampas-web-reels]].

## 배포 방식
S3 업로드 + CloudFront 무효화(정적 SPA), API는 PM2. 배포 전 매번 `web-edit` 타입체크+전체
테스트(500~580여 개)를 통과시키는 패턴이 일관됨.
