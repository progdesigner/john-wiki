# lampas-web-fit ("1분 플랭크 챌린지", `fit.lampas.io`)

`[[lampas-studio]]` 저장소(`lampas-system`)의 신규 앱(포트 **8462**). 음악 박자에 맞춰 운동하고
다음 동작을 미리 준비할 수 있게 카운팅해주는 서비스. 유튜브 쇼츠 "1분 플랭크 챌린지"를 참고점으로
[[progdesigner]]가 요청해 처음부터 구현됐다.

## 최초 구축 (2026-09-25~26, `Tool: codex`)
- 운동 타이머와 음악이 같은 오디오 시계 공유(일시정지·탭 이탈 시 동반 정지), 다음 동작 8박 전
  예고 + 마지막 4박 음성 카운트, 루틴 3종 + BPM·라운드·음악 설정, 운동 기록 저장, 모바일 지원.
- 음악은 라이선스 문제로 **내장 오리지널 비트**(합성 루프) 사용.
- 배포: 기존 `deploy-web.sh` 경로 + `fit.lampas.io` 전용 CloudFront 신규 생성 + 기존 Lampas
  와일드카드 인증서로 HTTPS. → [[2026-09-25-lampas-web-fit-구축-배포]]

## 대규모 반복 개선 (2026-09-26, `Tool: claude`, 제목 "Fit 서비스 개선")
같은 날 바로 이어진 훨씬 긴 세션에서 합성 음악·3루틴 구성이 실제 음원·영상 기반 단일 1분 챌린지로
전면 재구성됐다. 세션 상세는 [[2026-09-26-fit-서비스-개선]] 참고. 요약:

- **실제 음원 교체**: 사용자가 첨부한 mp3(Deti Rave, 160 BPM·152박·57초)를 박자 분석해 적용,
  이후 1분(160박=12초×5동작)에 맞춰 곡 구간·동작을 재설계(곡이 57초라 128박 지점에서 되감는 루프
  구간 설계). 트랙 아티스트 표기 "URYL"은 파일명에서 추정한 값(부정확할 수 있음).
- **동작 영상화**: 5동작(1·5번은 같은 동작 재사용) 각각 투명 webm 루프 영상을 붙임 — 사용자가
  제공한 영상이 맞지 않으면 재요청받아 수차례 교체(최종 02 플랭크 잭은 0.75초 루프로 3번째 교체).
  크로스 탭만 30초 원본(루프 버전 미제공)이라 무겁고(.mov 변환 시 5.8MB) 반복 지점이 어색한 채로
  남음.
- **투명 영상 크로스 브라우저 처리**: 캔버스 알파 검사로 VP9 webm이 불투명 디코딩되는 브라우저
  (Safari/iOS)를 감지해 HEVC 알파 `.mov`로 자동 전환, 둘 다 실패하면 동작 영역 전체를 검정으로
  칠함(이전엔 벡터 캐릭터 폴백이었으나 사용자 요청으로 완전 삭제, 빈 무대+텍스트로 교체).
  → [[transparent-video-browser-alpha-fallback]]
- **사이드바 제거·단일 챌린지 사이트로 축소**: 루틴 선택·템포·라운드·합성음악·코치팁 전부 제거,
  "오늘의 루틴" 카드 클릭 시 위 플레이어에서 해당 동작 미리보기(`stagedMove`).
- **디자인 반복(3회)**: 다크 네온 → "AI 티 줄이기"(영문 대문자 라벨→한국어 캡션, 장식 배지·숫자
  영문표기 제거, Claude 아티팩트 디자인 가이드 원칙 적용) → **밝은 모노톤 피트니스 센터 톤**(콘크리트
  배경·흰 카드·검정 잉크, Archivo+Noto Sans KR) → 사용자 피드백으로 **영상 플레이어 영역만 어두운
  차콜 톤으로 롤백**(페이지 나머지는 밝은 모노톤 유지, 현재 확정 상태).
- **배경 이미지 실험 → 롤백**: 매트 스튜디오 사진을 무대 배경으로 넣었다가(이 작업 중 HEVC 알파
  `.mov` 크로스브라우저 처리가 함께 도입됨) 사용자 요청으로 이미지만 제거, 단색 차콜 그라데이션
  복귀. HEVC 자동선택 로직은 유지.
- **ElevenLabs 코치 음성**: 'Domi'(여성, 또렷·자신감) 프리셋으로 준비·카운트·전환예고·완료 멘트
  15문장 사전 녹음, Web Audio 같은 시계로 박 단위 예약 재생. 완료 시 음악 컨텍스트를 음악 소스
  종료 즉시 닫아 마지막 멘트가 잘리던 버그를 "모든 소스 종료 후 닫기"로 수정.
  → [[elevenlabs]] · [[web-audio-context-close-after-last-source]]
- **메타데이터/SEO**: OG 이미지(1200×630, 동작 클립 프레임), apple-touch-icon·매니페스트(홈 화면
  추가 시 standalone), robots.txt·sitemap.xml, JSON-LD WebApplication, 카카오톡·슬랙 공유 미리보기.

## 검증 루틴
매 변경마다 vitest(최종 22개)·빌드·헤드리스 Chromium(Playwright)으로 전환 시각·음성 재생 시각을
설계값과 대조(10ms~수백ms 이내 일치) + 콘솔 오류 확인 → 배포 → 운영 200 응답 확인 → 커밋. fit 앱
경로만 선택적으로 커밋해 같은 작업 트리의 다른 세션 변경분(lampas-api-mcp OAuth 작업 등)과 분리.
