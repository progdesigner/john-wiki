# 사용 영역 페르소나 (use-area personas)

> ⚠️ **2026-07-16 04:26~04:32 세션에서 이 기능 전체가 폐기됨.** 아래 본문은 2026-07-08~09
> 구축 당시 설계를 그대로 보존한 기록이고, **현재 상태는 맨 아래 "폐기(2026-07-16)" 절**을
> 볼 것. 사용자 지시: "사용영역을 일반과 이미지로만 나누고 ... 페르소나를 이제 사용하지 마."

`[[lampas-harness]]`가 요청마다 에이전트([[lampas]])에게 **작업 영역별 전문가 페르소나**를
입히는 기능이었다(과거형). 사용자가 채팅에서 "사용 영역"을 고르면 해당 영역의 페르소나 프롬프트가
주입돼 답변의 톤·역할·작업 절차가 그 분야 전문가처럼 바뀌는 구조였다. `[[model-selection]]`
(어떤 모델로 실행할지)과 직교하는 축 — 페르소나는 *어떤 역할로* 일할지를 정했다.

## 구성 (2026-07-08 세션에서 구축)

6개 영역의 전문가 페르소나 프리셋:

| 영역 | 페르소나 |
|---|---|
| 비즈니스 | 15년차 전략 컨설턴트 |
| 브랜딩 | 브랜드 전략가 + 카피라이터 |
| 마케팅 | 전환 중심 시니어 마케터 |
| 이미지 | 아트 디렉터 |
| 영상 | 영상 PD + 작가 |
| 일반 | (아래 "정책 변천" 참고) |

- 조회·수정 API + 설정(⚙)의 "사용 영역 페르소나" 섹션 편집 UI.
- 수정본은 서버 `presets.json`에 저장, 다음 메시지부터 적용. 수정된 영역엔 ✏️ 표시, 초기화 가능.
- 도입 시 기존 "프롬프트 채우는 액션 버튼 칩"은 제거(이미지 영역 제외).

## "일반" 영역 정책 변천 (모순 명시)

이 항목은 두 세션 사이에서 **정의가 뒤집혔다** — 소스별로 명시한다:

- **2026-07-08** ([[2026-07-08-스케줄러-로컬llm-사용영역페르소나]]): "일반 = 페르소나 없음
  (= 기본 람파스)"로 정의. 즉 일반 선택 시 아무 역할도 덧입히지 않음.
- **2026-07-09** ([[2026-07-09-일반-사용영역-페르소나-설정]]): 사용자가 "일반에도 페르소나를
  설정하라"고 지시 → *비어있음 → 채움*으로 정책 변경. 구체 프롬프트 문구는 트랜스크립트에 미기재이고,
  트랜스크립트가 데몬 재시작 확인 직전에 끊겨 **반영 확정 여부는 미확인**.
- 계기: "페이블5 숨은 지시문" 프로모션 루머였으나, 원문 지침을 복제하지 않고 *취지(작업방식을 페르소나
  프롬프트로 명시)*만 참고해 직접 작성. 이 통념의 한계·보안 주의는 → [[system-prompt-mimicry-misconception]].

## 폐기 (2026-07-16)

2026-07-16 04:26~04:32 세션([[2026-07-16-사용영역-페르소나-폐기]])에서 사용자가 명시적으로
기능 폐기를 지시, 같은 세션에서 전면 구현:

- **UI 메뉴 축소**: 좌측 "사용 영역" 메뉴가 일반/이미지 2개만 남고 비즈니스·브랜딩·마케팅·영상
  4개는 숨김(코드에서 `CATEGORIES` 배열 항목 삭제, 조건부 숨김 아님). 이미지 영역만 화질·비율
  툴바 노출용으로 유지 — 페르소나와 무관한 별개 이유.
- **설정 화면 편집 UI 삭제**: 위 "구성" 절에 적힌 select/textarea/저장·초기화 UI 전체 제거.
- **백엔드 주입 로직 완전 삭제**: `DEFAULT_PRESETS`·`presetInstruction()` 등 `src/server.ts`
  내 페르소나 관련 코드 전부 제거. Claude Code SDK/로컬·OpenAI 호환/Gemini **3개 주입 경로**
  모두에서 페르소나 텍스트 주입 중단. `GET/POST /api/presets` API도 삭제.
- **저장소 정리**: `presets/*.md`(6개 프롬프트 원본 파일) `git rm`.
- 즉 위 "구성"·"일반 영역 정책 변천" 두 절이 기록한 6영역 페르소나 시스템은 **더 이상 코드에
  존재하지 않는다.** "일반" 정책이 비어있음→채움으로 바뀐 역사도 이제 무의미 — 애초에 어떤
  영역이든 페르소나가 주입되지 않으므로.
- 커밋은 이 세션 종료 후 이뤄짐: `7b27897`("refactor: presets 폴더 제거 및 서버 로직 정리",
  [[2026-07-16-잔여작업커밋-원격머지-재시작요청]] 참고). 이 세션 자체는 작업 트리 변경만 하고
  끝남(미커밋·미배포).
