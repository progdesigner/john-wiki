# 사용 영역 페르소나 (use-area personas)

`[[lampas-harness]]`가 요청마다 에이전트([[lampas]])에게 **작업 영역별 전문가 페르소나**를
입히는 기능. 사용자가 채팅에서 "사용 영역"을 고르면 해당 영역의 페르소나 프롬프트가 주입돼
답변의 톤·역할·작업 절차가 그 분야 전문가처럼 바뀐다. `[[model-selection]]`(어떤 모델로 실행할지)과
직교하는 축 — 페르소나는 *어떤 역할로* 일할지를 정한다.

## 구성 (2026-07-08 세션에서 구축)

6개 영역의 전문가 페르소나 프리셋:

| 영역 | 페르소나 |
|---|---|
| 비즈니스 | 15년차 전략 컨설턴트 |
| 브랜딩 | 브랜드 전략가 + 카피라이터 |
| 마케팅 | 전환 중심 시니어 마케터 |
| 이미지 | 아트 디렉터 |
| 영상 | 영상 PD + 작가 |
| 일반 | (아래 "정책 변천" 참고) |

- 조회·수정 API + 설정(⚙)의 "사용 영역 페르소나" 섹션 편집 UI.
- 수정본은 서버 `presets.json`에 저장, 다음 메시지부터 적용. 수정된 영역엔 ✏️ 표시, 초기화 가능.
- 도입 시 기존 "프롬프트 채우는 액션 버튼 칩"은 제거(이미지 영역 제외).

## "일반" 영역 정책 변천 (모순 명시)

이 항목은 두 세션 사이에서 **정의가 뒤집혔다** — 소스별로 명시한다:

- **2026-07-08** ([[2026-07-08-스케줄러-로컬llm-사용영역페르소나]]): "일반 = 페르소나 없음
  (= 기본 람파스)"로 정의. 즉 일반 선택 시 아무 역할도 덧입히지 않음.
- **2026-07-09** ([[2026-07-09-일반-사용영역-페르소나-설정]]): 사용자가 "일반에도 페르소나를
  설정하라"고 지시 → *비어있음 → 채움*으로 정책 변경. 구체 프롬프트 문구는 트랜스크립트에 미기재이고,
  트랜스크립트가 데몬 재시작 확인 직전에 끊겨 **반영 확정 여부는 미확인**.
- 계기: "페이블5 숨은 지시문" 프로모션 루머였으나, 원문 지침을 복제하지 않고 *취지(작업방식을 페르소나
  프롬프트로 명시)*만 참고해 직접 작성. 이 통념의 한계·보안 주의는 → [[system-prompt-mimicry-misconception]].
