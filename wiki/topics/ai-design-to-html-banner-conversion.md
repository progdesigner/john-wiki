# AI로 배너 디자인 이미지를 HTML로 직접 변환

## 인사이트
기존 배너 제작 워크플로우: 디자인 이미지를 좌/우/배경 등 2~3조각으로 쪼개고, 이를 실서비스
("Response UI")에서 조합하는 구조를 별도로 설계해야 했음 — 이미지를 그대로 쓸 수 없는 제약 때문.

[[progdesigner]]가 깨달은 점: AI(비전 모델)에게 **디자인이 끝난 배너 이미지**를 통째로 보여주면,
이미지 분해 없이 **한 번에 Response UI에 맞는 배너 HTML**로 변환해준다. 디자인이 복잡해도 결과는
동일 — 이미지 조각 조합이라는 중간 구조 설계 단계 자체가 불필요해짐.

실제 사례: "복지리 앱(토스)" 배너를 이 방식(이미지 조각 조합이 아닌 HTML 직접 코딩)으로 제작함
(원문 표기 "복지리 앱인토스" 그대로 — 정확한 제품 정체는 미상, [[2026-07-15-삼성전자-주식분할-배너-html-인사이트]] 참고).

## 파생 제품 아이디어
배너 디자인 이미지를 복사/붙여넣기만 하면 AI가 즉시 커스텀 HTML 배너를 생성해주는
**셀프서비스 툴**을 만들면 수요가 있을 것 같다는 제안. 아직 구체 스펙·착수 여부는 미정 —
아이디어 단계에서 기록됨.

## 미확인 사항
- "Response UI"가 CWC 내부 서비스/디자인시스템 고유명사인지, 일반적 표현인지 소스로는 불명확.
- 이 인사이트가 나온 계기(첨부 사진 원본 내용)는 소스 텍스트에 남아있지 않음 — 어시스턴트의 요약만
  근거로 기록.
- 제품화(셀프서비스 툴) 착수 여부는 후속 세션에서 확인 필요.
