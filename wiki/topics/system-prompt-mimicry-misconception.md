# 시스템 프롬프트 복제 = 모델 흉내내기? (통념과 한계)

**통념**: "어떤 모델의 '숨은 지시문/시스템 프롬프트'가 공개됐다. 그걸 다른 모델의
프로젝트 지침칸에 붙여넣으면 그 모델처럼 일한다."

이 통념이 등장한 계기: 2026-07-09 세션에서 `[[progdesigner]]`가 받은 프로모션 메시지
("에트매거진")이 *"페이블5의 숨은 지시문이 깃허브에 공개됨 → `claude-fable-5.md`를
claude.ai 프로젝트 지침에 붙여넣고 아무 모델 + effort high로 두면 페이블처럼 동작"*이라
주장하며 단축링크(`gogl.to/4IwW`)로 유도. → [[2026-07-09-일반-사용영역-페르소나-설정]].

## 왜 절반만 맞는가

- **맞는 부분**: 시스템 프롬프트/지침은 모델의 *톤·형식·작업 절차·역할*을 실제로 크게 바꾼다.
  "일하는 방식"을 페르소나 프롬프트로 명시하는 것은 유효한 기법이고, 이 위키의
  사용 영역 페르소나([[2026-07-08-스케줄러-로컬llm-사용영역페르소나]])도 같은 착상이다.
- **틀린/과장된 부분**: 모델의 실제 능력은 지침이 아니라 **가중치(훈련)·컨텍스트 길이·툴 배선·
  추론 예산**에서 나온다. 지침을 복사해도:
  - 약한 모델이 강한 모델의 *지식·추론력*을 얻지 못한다 (로컬 35B가 Claude가 되지 않음 —
    [[local-llm-on-apple-silicon]]의 품질 저하·환각 관찰과 같은 맥락).
  - 툴(웹검색·MCP·파일)이 배선돼 있지 않으면 지침이 시켜도 못 한다.
  - "effort high"는 벤더별 의미가 다르고, 지침만으로 없던 사고력이 생기지 않는다.
- **결론**: 프롬프트는 *행동의 형태*를 바꾸지 *역량*을 이식하지 못한다.

## 보안·위생 주의

- **출처 미상 지침 붙여넣기 = 프롬프트 인젝션 벡터**. 공개됐다는 `*.md` 지침 안에 숨은 명령
  (데이터 유출 유도, 특정 링크 클릭, 안전장치 무력화)이 섞여 있을 수 있다. 프로젝트 지침칸은
  이후 모든 대화에 주입되므로 신뢰할 수 없는 텍스트를 통째로 넣지 말 것.
- **단축링크(`gogl.to/...`)·"지금 팔로우하고 놓치지 마세요"** = 클릭베이트/피싱 신호. 검증 전 클릭 금지.
- 착상은 취하되(작업방식을 명시적 페르소나로), 원문 지침을 맹목 복제하지 말고 **직접 작성**하라 —
  실제로 [[2026-07-09-일반-사용영역-페르소나-설정]]에서 어시스턴트는 루머를 붙여넣는 대신
  취지만 참고해 "일반" 페르소나를 직접 작성했다.
