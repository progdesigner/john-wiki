# 2026-07-16 — 커밋·push 정리 + quick.html 작업 폴더 선택기 (신규 확인)

`[[progdesigner]]`가 "지금까지 작업한 모든 코드를 커밋할 게 있으면 커밋하고 push해줘"라고 요청한
1왕복 quick 세션. 소스: `raw/conversations/2026-07-16-quick-작업폴더선택기-커밋푸시.md`
(원본 경로 `logs/chats/archive/quick-62e7d2bc-6326-421e-84ac-e7beb0bffdc9.md`).

## 진행

diff 확인 → 스테이징 → 커밋(`c100edd`) → push. `main → origin/main` 정상 반영, 버전 **v0.1.27**.

커밋에 포함된 변경 내용 5가지 중 4가지는 이미 위키에 기록된 작업의 반영(push) 확인이고, 1가지는
이 세션에서 처음 확인된 새 정보다:

| 변경 | 위키 상태 |
|------|-----------|
| 대화 목록 항목 롱프레스(0.6초) 보관 확인 | 기록됨 → [[2026-07-15-auto모델-난이도판정-확인ux-개선]] §4 |
| "■ 중지" 버튼 재클릭 확인(3초 유예) | 기록됨 → [[2026-07-15-auto모델-난이도판정-확인ux-개선]] §3 |
| 음성 입력 시작 시 진동+비프 피드백 | 기록됨 → [[2026-07-16-음성입력-진동비프-피드백]] |
| Auto 모델 선택기 extreme 티어(claude-fable-5) | 기록됨 → [[2026-07-15-auto모델-난이도판정-확인ux-개선]] §2 |
| **quick.html에 작업 폴더 선택기 추가** | **신규** — 이전 세션에 언급 없음 |

새 정보: `apps/web/public/quick.html`(퀵 채팅 오버레이, [[lampas-harness]] 참고)에 작업 폴더
선택기가 추가되어, **첫 턴 이후 그 대화가 선택된 폴더에 묶인다**(work-folder scoping을 quick 채팅
쪽에도 확장한 것으로 추정 — 상세 구현은 이 세션 요약에만 언급되고 코드 근거는 조사되지 않음).
기존 [[work-folder-sandboxing]] 스킬(에이전트를 작업 폴더 안으로 제한)과 관련될 가능성이 있으나
quick.html 쪽 구체 동작은 후속 확인 필요.

## 결정사항

- v0.1.27의 5개 변경사항 모두 커밋 `c100edd`로 `main`에 반영, origin push 완료.
