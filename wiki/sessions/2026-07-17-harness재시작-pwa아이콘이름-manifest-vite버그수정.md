# 2026-07-17 하네스 재시작 + PWA 이름/아이콘 변경 + Vite manifest 버그 수정

12:40:59~12:48:31 UTC. [[2026-07-17-env읽기-pwa세이프에어리어-여백수정]] 세션(같은 날 12:50~12:55
UTC)보다 **2분 앞서** 끝난 선행 세션 — PWA `header` safe-area 여백 수정보다 먼저, PWA 자체를
처음 설정한 세션이다.

## 개요
1. 모호한 프롬프트 2연속("제 시작해줘", "지금 하늘은")에 어시스턴트가 추측 답변 대신 되물어 명확화
   요청 — 실행 없이 종료된 초반 왕복 2개, 콘텐츠 가치 낮음.
2. **하네스 재시작** — "스크립트 있잖아 재시작하는 스크립트 그걸 실행해서 재시작해줘"(동일 요청 반복
   2회). 어시스턴트가 `scripts/` 디렉토리에서 재시작 스크립트(`restart-lampas.sh`로 추정)를 찾아 실행,
   18초 후 새 프로세스(PID `74969`, `dist/index.js serve`) 기동 확인 + MCP 서버(naver-blog, threads)
   재연결까지 확인. → [[self-hosted-agent-server-ops]] 정석 패턴(지연·분리 실행) 재확인 사례.
3. **PWA 이름/아이콘 최초 설정** — 사용자가 "홈에 추가해서 PWA로 바꾸면 이름을 영어로 L 대문자인
   람파스(음성전사가 '남파스'로 나옴)로 바꾸고 아이콘은 첨부 이미지로 바꿔줘" 요청, 사진 1장 첨부.
   - 어시스턴트가 `apps/web/public/`에 `manifest.json`이 없는 것을 확인, 새로 생성.
   - 첨부 이미지(흰색 "L" 모양 아이콘, 1024×1024 PNG)를 작업 폴더 안에서 찾아 192px/512px 두 사이즈로
     리사이징해 저장.
   - `manifest.json`: 앱 이름 "Lampas", 짧은 이름 "Lampas", 아이콘 192/512 경로 지정.
     `index.html`에 manifest 링크 + Apple 메타 태그(iOS PWA 대응) 추가.
   - 웹 빌드(v0.1.37) 후 `dist/`에 반영 확인.
4. **재시작 요청 → Vite 버그 발견·수정** — 사용자가 "재시작해서 홈에 추가할 때 아이콘·이름이 적용되게
   해줘"라고 요청하자, 어시스턴트가 재시작이 아니라 **빌드 파이프라인 버그**를 발견:
   - 원인: Vite가 `root: 'public/'` + `publicDir: false`로 설정돼 있어, `index.html`이 참조하는
     `manifest.json`/`icon-192.png` 같은 파일이 Vite의 **에셋 파이프라인을 타고 base64 인라인 또는
     해시된 파일명**으로 바뀌었다. 그런데 `manifest.json` **내부**에 적힌 아이콘 경로(`/icon-512.png`
     등)는 해시 없이 원래 경로 그대로 남아 있어, 실제 배포된 파일명과 어긋나 깨진 상태였다.
   - 수정: `manifest.json`+아이콘 4종을 별도 정적 디렉토리 `apps/web/static/`으로 분리하고
     Vite `publicDir`로 지정 → 재빌드. 결과: `manifest.json`이 순수 파일로, 아이콘 경로도 해시 없이
     그대로 `dist/`에 배포됨.
   - 검증: `curl`로 `manifest.json` 200/JSON, 아이콘 둘 다 200/PNG, `index.html`의 manifest 링크도
     순정 경로로 나옴을 확인.
   - **재시작 불필요 판단**: 정적 파일은 서버가 매 요청마다 디스크에서 읽으므로, 서버 프로세스
     재시작 없이 즉시 반영됨 — 사용자가 요청한 "재시작"은 실제로 필요 없었고 빌드+배포만으로 해결.
   - → 재사용 절차 스킬 추출: [[vite-publicdir-manifest-icon-fix]]

## 관찰
- **`apps/web/static/` 디렉토리의 최초 생성 세션** — [[lampas-harness]] 엔티티 페이지의
  2026-07-18 아이콘 통일 세션(`icon-source-of-truth-before-replace`)이 이미 존재하는 것으로 전제하고
  다루는 `apps/web/static/icon-512.png` 등이 바로 이 세션에서 만들어진 디렉토리·파일이다.
- **⚠️ 아이콘 디자인 불일치**: 이 세션에서 설정된 아이콘은 사용자가 첨부한 **흰색 "L" 로고**였는데,
  [[2026-07-18-desktop-web-아이콘-통일]] 세션 기록은 그 시점 `apps/web/static/` 아이콘을
  **"남색 막대(사운드바)" 디자인**으로 서술한다. 즉 이 세션(07-17 12:48) 이후 ~07-18 사이 어느
  시점에 웹 아이콘이 흰색 "L" → 남색 사운드바로 **한 번 더 바뀐 것으로 보이나, 그 변경 세션은
  아직 위키에 없다** — 소스 미확인, 추후 ingest 시 확인 필요.
- **음성전사 오류 관찰**: 사용자가 "람파스"라고 말한 것으로 추정되는 발화가 "남파스"로 전사됨
  (ㄹ→ㄴ 초성 변형, 한국어 두음법칙/STT 흔한 오류 패턴). 사용자가 "영어로 L 대문자"라고 스스로
  덧붙여 모호성을 해소함 — 어시스턴트 쪽 확인 요청 없이도 자체 해소된 사례.
