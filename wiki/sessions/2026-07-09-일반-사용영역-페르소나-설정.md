# 2026-07-09 세션 — "일반" 사용 영역 페르소나 설정 (페이블5 지침 루머 계기)

## 흐름

1. **파일 경로 분석 문의**: `[[progdesigner]]`가 "내 파일 경로 분석은 되나?"라고 물음.
   어시스턴트는 경로 구조/권한/시맨틱/보안 위험 분석은 가능하나 실제 파일시스템 접속·수정은 못 한다고 답변
   (당시 이 대화 맥락에선 파일 도구 미노출).
2. **페이블5 지침 루머 붙여넣기**: 사용자가 'AI TREND 전문 매거진 에트매거진' 프로모션 메시지를 붙여넣음.
   요지: *"페이블5의 '숨은 지시문'이 깃허브에 통째로 공개됐다. `claude-fable-5.md`를 claude.ai 프로젝트
   지침칸에 붙여넣고 아무 모델 + effort high로 두면 다른 모델도 페이블처럼 일한다"* + 단축링크(`gogl.to/4IwW`).
   → 어시스턴트 응답은 **[사용자에 의해 중지됨]**.
3. **작업 지시**: "위 내용을 보고 **일반** 에 사용 영역의 페르소나를 설정해줘." (동일 요청 4회 반복 — 빌드/재시작
   대기 중 사용자의 조급한 재전송으로 보임.)
4. **수행**: 어시스턴트가 사용 영역 프리셋 정의 위치를 찾아 "일반" 페르소나를 작성 → 빌드 완료 →
   데몬 재시작으로 반영 확인 단계. **트랜스크립트는 데몬 재시작 완료 확인 직전에 끊김**(미확정).

## 핵심 내용 / 결정사항

- **"일반" 영역에 페르소나 부여** — 프로모션 메시지의 취지(모델의 "일하는 방식"을 지침으로 옮기기)를
  참고해 `[[lampas-harness]]`의 사용 영역 프리셋 중 "일반"에 전문가/작업방식 페르소나 프롬프트를 채움.
- ⚠️ **기존 정의와의 모순(중요)**: 직전 2026-07-08 세션에서는 "일반 = 페르소나 없음(=기본 람파스)"로
  정의했다([[2026-07-08-스케줄러-로컬llm-사용영역페르소나]]). 이 세션에서 사용자가 "일반"에도 페르소나를
  **설정하도록 지시**하여, 정책이 *비어있음 → 채움*으로 바뀜. (구체 프롬프트 문구는 트랜스크립트에 미기재.)
- 사용 영역 페르소나 UI/프리셋 구조 자체는 [[2026-07-08-스케줄러-로컬llm-사용영역페르소나]]에서 구축된 것을 재사용.

## 관찰 / 주의

- **페이블5 "숨은 지시문" 루머는 마케팅·피싱성**: 공개된 시스템 프롬프트를 붙여넣는다고 다른 모델이 그 모델처럼
  동작하진 않는다(모델 행동 = 가중치·후련·툴 배선의 산물이지 지침만이 아님). 단축링크·"팔로우 유도"는 클릭베이트
  신호. → 별도 정리: [[system-prompt-mimicry-misconception]].
- 다만 **거기서 얻은 아이디어(작업방식을 페르소나 프롬프트로 명시)** 자체는 유효 — 실제로 "일반" 페르소나
  작성에 활용됨. 루머는 걸러내되 착상은 취한 사례.
- **동일 요청 4회 반복**: 사용자가 빌드/재시작 진행 상황을 못 보고 재전송. 진행 중 상태 가시성 부족 신호.
