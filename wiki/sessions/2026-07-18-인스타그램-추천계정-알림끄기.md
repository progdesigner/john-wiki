# 2026-07-18 — 인스타그램 추천 계정 알림 끄기 세션

`[[progdesigner]]`가 인스타그램(제품 [[lampas-studio]]/[[instagram-reference-integration]]과 무관한
**개인 소비자 앱**)에서 추천 계정·추천 게시물 알림을 끄는 방법을 물은 개발과 무관한 개인 질문. 웹 검색
기반으로 두 차례 답변.

기간: 2026-07-18T15:12:28Z ~ 2026-07-18T15:23:01Z UTC (2왕복 quick).
원본: [[raw/conversations/2026-07-18-인스타그램-추천계정-알림끄기]] (아카이브 파일명
`quick-855ee19c-6240-49ac-b2e5-3f103dafbe4f.md`)

## 흐름 (2왕복)

1. **user**: "인스타그램에 추천 계정 알림이 안오게 하려면? 검색해서 알려줘"
2. **assistant**: 웹 검색 후 4가지 방법 정리 — 피드 추천 콘텐츠 숨기기, 홈탭 팔로우 추천 끄기,
   알림 자체(이메일/SMS/푸시) 끄기, 내 계정이 타인에게 추천되지 않도록 끄기.
3. **user**: "최신 상태를 검색해서 최신 인스타그램으로 다시 알려줘 지금은 추천 게시물 끄기를 찾을 수
   없어" — 1차 답변의 메뉴 경로가 실제 앱과 안 맞는다는 피드백.
4. **assistant**: 재검색 후 "최신(2026년 기준)" 경로로 갱신 — 설정 및 개인정보 → 알림 → 게시물,
   스토리 및 댓글에서 **"회원님을 위한 추천 게시물"**, **"첫 게시물과 스토리"** 항목을 끄는 방법(방법 1),
   기존 추천 알림 개별 스와이프→"이 유형의 알림 해제"(방법 2), OS 레벨 알림 전체 차단(방법 3, 갤럭시/
   아이폰 경로 병기)을 제시. **"푸시 알림만 꺼지는 것이며 피드 내 추천 게시물 자체는 기능적으로 완전히
   끌 수 없다"**는 한계를 명시.

## 핵심 관찰

- **콘텐츠 가치 낮음** — 개발/업무와 무관한 1회성 소비자 앱 설정 질문. 프로젝트 상태·결정·재사용
  절차 없음.
- 1차 답변이 실제 앱 UI와 어긋나 사용자가 "최신 상태로 다시" 재요청한 패턴 — 앱 UI 관련 질문에
  어시스턴트의 사전지식이 낡아있을 수 있어 웹 검색 재확인이 필요했던 사례.
- 이 세션의 "인스타그램"은 `[[instagram-reference-integration]]`(lampas-studio의 레퍼런스 이미지
  통합 기능)과는 전혀 다른 맥락(개인 소비자 앱 사용)이다 — 동명이의 혼동 주의.
