# 2026-07-13 모델별 시간당 코딩 비용

1왕복 quick 질의응답 (2026-07-13 14:29). "클로드로 코딩을 1시간 하면 모델별로
비용이 얼마나 드나?"에 대한 API 종량제 기준 추정. 상세 단가·산정 로직은

## 질문
- 사용자: "클로드로 코딩을 1시간 한다고 하면 모델별로 비용은 얼마나 들까?"

## 답변 요지 (어시스턴트 추정)
Claude Code 1시간 "보통 강도" 코딩의 API 종량제 추정 비용:

| 모델 | 입력/출력 (1M 토큰) | 1시간 추정 |
|---|---|---|
| Fable 5 | $10 / $50 | $20~50 |
| Opus 4.8/4.7/4.6 | $5 / $25 | $10~25 |
| Sonnet 5 | $3 / $15 (~2026-08-31 프로모션 $2 / $10) | $5~15 (프로모션 $3~10) |
| Sonnet 4.6 | $3 / $15 | $5~15 |
| Haiku 4.5 | $1 / $5 | $2~5 |

- **산정 가정**: Claude Code는 프롬프트 캐싱을 강하게 써서 비용 대부분이 캐시 읽기
  (입력가 ×0.1)와 출력에서 발생. "보통 1시간" = 요청 ~40회, 캐시 읽기 누적 ~12M,
  캐시 쓰기 ~2M(입력가 ×1.25), 신규 입력 ~0.4M, 출력 ~0.2M 토큰.
  → Opus 4.8 ~$25, Sonnet 5 ~$15, Haiku ~$5.
- **편차 요인**: (1) 컨텍스트 크기(큰 저장소일수록 캐시 읽기↑)·effort 설정, 가벼운
  사용은 ~1/3, 헤비(대규모 리팩터·장시간 에이전트)는 2배+. (2) API 종량제 대신
  Claude Pro/Max **구독**이면 시간당 한도 내 추가 과금 없음 → 매일 몇 시간 쓰면 구독이 유리.
- 이 하네스([[lampas-harness]]) 기본 모델은 [[model-selection]] 기준 Opus 4.8 → 시간당 대략 $10~25.
- 정확한 실측은 세션 로그의 `usage` 필드(입력·출력·캐시 토큰) 집계로 가능하다고 제안.

## 메모 / 주의
- 위 단가·추정은 **어시스턴트가 답변 시점(2026-07-13)에 제시한 값**이다. 프로모션 종료일
  (Sonnet 5 ~2026-08-31)·모델 라인업은 시간이 지나면 낡을 수 있으니 실사용 전 재확인 권장.
- 실측 집계는 이 세션에서 실행하지 않음(제안만). `usage` 필드 기반 시간당 비용 산출은
  후속 작업으로 남음.
