# 2026-09-24 Pulse 페르소나·카피 점수 구조화 개선

## 배경 — Pulse란 무엇인가 (이 세션에서 처음 상세 확인)

[[lampas-agent]] 페이지가 "Pulse는 페르소나/카피 신뢰도 점수를 계산하는 하위 시스템으로 추정"이라고
**미확인 상태로 남겨뒀던 부분**이 이 세션으로 해소됨. Pulse는 [[lampas-agent]]가 수집한 인기 릴스
(캡션·댓글 등 원문)를 근거로 [[lampas-web-copy]]("Copy")의 **페르소나 생성 + SNS 카피 생성·채점**을
담당하는 파이프라인이다.

## 문제 제기 (사용자)

> "pulse 에서 페르소나가 정말 근거 있게 만들어 지는 것 같지 않아. 너무 유아틱해 ... 카피 만들때도
> 페르소나 기반으로 더 후킹했으면 하는데 일반적인 수준이야 점수는 높다 나오는데"

## 진단

- 페르소나가 "팬층의 반복 행동"보다 **진행자의 이름·말투**를 먼저 만들고, 근거 릴스 ID만 형식적으로
  붙어도 저장됨 — 실제 캡션·댓글 원문 검증 없음.
- 카피 평가는 구체적 팬 반응 근거 없이도 고득점 가능, 기존 영상의 훅 점수 자체가 심사 입력으로
  재사용돼 순환 참조.
- 조회수를 임의로 나눠 "팬덤 인원"을 추정 표시하던 기능 — 근거 없는 추정치로 판단, 제거.

## 1차 개선 — 구조화 채점 (배포 완료)

사용자가 "점수를 좀 더 구조화 해줘"라고 재요청해 4영역 8세부항목 채점표로 재설계:

| 영역 | 세부 배점 |
|---|---|
| 훅 25점 | 구체적 관찰 15 + 궁금증·긴장 10 |
| 이해도 25점 | 즉시 이해 15 + 목적 적합성 10 |
| 팬층 적합성 25점 | 욕망·갈등 연결 15 + 영상 사실 일치 10 |
| 자연스러움 25점 | 언어·리듬 15 + 과장 절제 10 |

- 각 항목에 **원문 구절·채점 이유·개선안**을 붙여 서버가 합산.
- **감점 상한**: 범용 문구·팬층 근거 부족 → 총점 **69점** 상한, 영상에 없는 사실 주장 → **49점** 상한.
- 페르소나는 수집 릴스의 캡션·댓글 원문을 검증하고 팬층의 상황·욕망·갈등·재방문 이유를 정의하며,
  확인 안 된 해석은 "가설"로 표시.
- 조회수 기반 팬덤 인원 추정치 제거.
- 검증: 테스트 94개, 타입 검사·웹 빌드 통과. **이 시점엔 미배포** — 기존 페르소나·카피는 재생성·
  재채점해야 새 기준 적용.

## 2차 상담 — "더 마케팅적으로 후킹한 제목" (방향 논의만, 미구현)

사용자가 페르소나·카피를 더 똑똑하게 만들 방법을 묻자, 어시스턴트가 4단계 설계를 제안:

1. 인기 릴스의 성공 이유를 "기존 기대 → 어긋난 지점 → 확인하고 싶은 결말" 구조로 분해(채널 평소
   성과 대비 비교로 규모발 인기와 구분).
2. 페르소나마다 "반응하는 긴장"을 구체화(예: "복귀 선수를 응원하지만 경기력이 돌아왔는지 직접
   확인하고 싶은 팬").
3. 제목을 바로 쓰지 않고 손실회피·통념반박·판단기준·팬 논쟁 등 **마케팅 각도**를 먼저 경쟁시켜 고름.
4. 심사에서 감점만 하지 않고 지적("너무 범용적", "궁금증의 답을 영상이 안 준다")을 받아 **재작성**,
   좋은 후보가 없으면 억지로 우승작을 고르지 않고 자료 부족 표시.

## 사용자 반박 — 예시가 오히려 역효과 ⚠️ 방향 수정 지점

어시스턴트가 예시로 든 "복귀 첫 안타보다 먼저 볼 건 발 위치"(분석적·상세) vs "드디어 돌아온
이정후"(일반적)를 대비하며 후자를 "일반적이라 약하다"고 폄하했으나, **사용자가 반대로 "일반적인
제목이 더 좋아보이는데?"라고 반박** → 어시스턴트가 정정:

- "드디어 돌아온 이정후"는 **짧고 익숙해도 좋은 훅**(누구·무슨 일 즉시 전달 + 팬의 기다림을 건드림).
  "발 위치" 예시는 근거 없이 디테일만 넣은 것으로, 오히려 이게 약한 예시였음.
- **핵심 구분**: "일반적인 표현"(좋음, 감점 대상 아님) ≠ "아무 영상에나 붙는 빈말"(예: "역대급
  충격적인 순간" 같은 근거 없는 과장, 감점 대상).
- 1차 개선에서 도입한 **"익숙한 표현 69점 상한"이 너무 기계적이었다는 자기 정정** — 좋은 제목까지
  탈락시키는 부작용을 인정.
- 새 평가 기준: 즉시 이해(누구·무슨 얘기) / 팬의 감정(기대·응원·아쉬움·호기심) / 영상과 일치 / 표현의
  경제성(불필요한 설명 없이 짧고 자연스러움).

## 2차 개선 — 배포 완료

사용자 지시("이런 방향으로 될 수 있게 다시 개선해주고 배포해줘")로 반영·배포:

- **직관적인 제목을 10개 중 최소 6개** 만들도록 생성 로직 변경.
- **"익숙한 문구" 69점 상한 완전 제거**.
- 페르소나도 갈등·분석 취향을 억지로 만들지 않고 응원·기다림·반가움까지 반영.
- 사실과 다른 과장(영상에 없는 주장)에 대한 감점은 유지.
- 테스트 105개 통과 → 저장소 배포 스크립트로 API + Copy 웹 배포. **API 전체 테스트 1,152개, 웹
  36개** 통과, 운영 응답 확인까지 완료.
- 새로 생성하는 페르소나·카피부터 새 기준 적용, 기존 카피는 재채점 필요.
