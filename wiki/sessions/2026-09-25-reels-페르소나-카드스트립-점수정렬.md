# 2026-09-25 — Reels 페르소나 카드 스트립 + 점수순 정렬

`Tool: claude` 세션(22:51:58Z 시작, 작업폴더 `lampas-system`). [[lampas-web-reels]]의 페르소나
선택 UI를 [[lampas-web-copy]]와 같은 디자인 언어로 맞추고, 이어서 페르소나·카피 모두 점수 기준
정렬을 추가한 두 왕복짜리 짧은 세션. [[2026-09-25-스포츠위키-경기엔티티-설계구현]] 세션의 ingest
당시 이미 raw로만 존재가 확인됐던("미정식 ingest") 세션이 이번에 정식으로 위키에 반영됨.

## ① 페르소나 선택 → 가로 스크롤 카드 스트립
스크린샷(MLB·NBA 페르소나 혼재) 첨부와 함께 "칩 나열 대신 카드 형태로, 오른쪽 스크롤로 선택"
요청. Copy 앱의 카드 스트립 구현을 참조해 `PersonaSelect`를 다시 작성:
- **카드**: 260px 폭, 스냅 스크롤. 이름·분야/카테고리 배지·설명 3줄·타겟·근거 클립 수 표시.
  맨 앞 카드는 "페르소나 없음".
- **분야 필터 칩**: 스트립 위에 "전체 / 스포츠·MLB / 스포츠·NBA"처럼 분야·카테고리별 칩이 개수와
  함께 나타나 카드 목록을 좁힌다. 이미 선택된 페르소나는 필터와 무관하게 항상 목록에 남는다.
- **선택 유지**: 페르소나를 고르면 해당 카드가 보이도록 스트립이 자동 스크롤되고, 아래에
  이름·설명·"왜 필요한가" 한 줄이 표시된다. 카피 선택 초기화 동작은 그대로 유지.
- 순수 로직은 `apps/lampas-web-reels/src/lib/editGroup.ts`에 두고 테스트 추가 — vitest 84개,
  tsc 통과. `deploy-web.sh`로 reels 배포(CloudFront 무효화, `.env.smoke` 미설정으로 스모크
  테스트는 생략). **커밋 `c7fda05b`** — 작업 트리에 섞여 있던 `lampas-agent` env·`lampas-web-fit`
  변경은 메모리 규칙에 따라 이 커밋에서 제외.

## ② 페르소나·카피 점수순 정렬
"카피나 페르소나를 점수 순으로 보여줘" 요청. API가 이미 `confidence`(신뢰도)·`review`(교차 심사)
값을 내려주고 있어 **백엔드 변경 없이 프론트만 수정**:
- **페르소나 카드**: Pulse가 계산한 신뢰도 점수 내림차순 정렬, 점수 없는 페르소나는 맨 뒤.
  같은 이름·타겟이 여러 개면 점수 높은 쪽만 남기고 중복 제거. 카드 하단에 "신뢰도 높음 82점 ·
  교차 심사 70점" 형태로 보라색 표시, 미계산 시 "신뢰도 미계산".
- **카피 run 칩**: 최고 점수 순 정렬, 점수 없는 run은 뒤로, 동점이면 최신순. "최고 N점" 배지
  강조 + 첫 칩(최고점 run) 자동 선택. run 안 카피 10개는 API가 이미 채점 순위로 내려주므로 변경 없음.
- 순수 로직은 마찬가지로 `editGroup.ts`에 정렬·중복 제거·점수 표시 테스트 추가 — vitest 86개,
  tsc 통과. reels 배포·**커밋 `5dc469b2`**.
