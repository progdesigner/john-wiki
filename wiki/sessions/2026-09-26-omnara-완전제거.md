# 2026-09-26 Omnara 완전 제거

`[[progdesigner]]`가 맥미니에서 **Omnara**(외부 소프트웨어 — [[omnara]] 엔티티가 지금까지
기록해온 "durable-agent 런타임 레퍼런스 코드"와 별개로, **실제로 설치돼 상주 데몬으로 돌던
앱**임이 이번에 처음 드러남)를 완전히 제거해 달라고 요청, 조사 후 삭제까지 한 세션에서 완료.

## 발견된 설치 형태
- 데몬이 `~/Library/LaunchAgents/com.omnara.daemon.plist`로 LaunchAgent 등록, 프로세스 상주 중.
- 본체는 `~/.omnara`에 위치 — `Omnara.app`, CLI 바이너리, `claude_wrapper`, `omnara-voice`,
  자격 증명 파일, 로그 전부 포함. 용량 512MB.
- `~/.omnara/worktrees`에 git worktree 4개 — 전부 빈 디렉터리(커밋 안 된 작업 없음, 확인 후 안전 삭제 판단).
- `.zshrc`에 omnara PATH 설정 3줄.
- `~/Library/Caches/claude-cli-nodejs` 아래 Omnara 워크트리 경로 기준 캐시 3개.
- `~/.claude.json`에 옛 Omnara 워크트리 경로의 프로젝트 항목 14개, `~/.claude/projects`에 그
  경로 세션 기록 2개 — Claude Code 자체 데이터(대화 기록)라 판단해 **삭제하지 않고 보존**.

## 제거 절차 (실행 순서)
1. 데몬 프로세스 종료
2. LaunchAgent 등록 해제(`launchctl bootout`) + `com.omnara.daemon.plist` 삭제
3. `~/.omnara` 디렉터리 전체 삭제
4. `.zshrc`의 PATH 설정 3줄 제거
5. 관련 캐시 삭제
6. 사후 검증: Homebrew/pipx/uv/npm 어디에도 패키지 없음, `/Applications`에도 앱 없음 확인. 삭제
   후 프로세스·launchctl·파일 경로 재조회로 잔여물 없음 확인.

이 6단계 절차는 재사용 가능한 패턴으로 일반화해 [[macos-app-complete-uninstall]] 스킬로 추출.

## 위키 기존 기록과의 관계 (중요 — 모순 아님, 새 사실)
- [[macos-launchctl-cleanup-candidates]](2026-07-16 launchctl 감사)의 원시 로그에 이미
  `com.omnara.daemon`이 찍혀 있었으나, 그 세션에서는 분석·정리 후보 목록에 오르지 않고
  누락됐었다 — 최소 2026-07-16부터 맥미니에 Omnara가 설치돼 있었다는 뜻.
- [[omnara]] 엔티티는 지금까지 "[[lampas-agent]] 개선 설계를 위해 분석한 외부 레퍼런스
  코드베이스"로만 기록돼 있었다(2026-09-18 세션). 이번 세션으로 **같은 이름의 실제 소프트웨어가
  맥미니에 별도로 설치·상주해 있었다**는 사실이 추가로 확인됨 — 코드 분석과 실사용 설치는
  별개 사건이었다.
