# 2026-07-11 — 기억 요약 요청·wiki 경로/WIKI_DIR 확인 세션

`[[progdesigner]]`가 `[[lampas-harness]]` 채팅에서 "지금까지 기억에 저장된 내용 요약해줘"라고 물으며
시작한 짧은 세션. 어시스턴트가 **장기기억을 조회할 도구가 여전히 없다**는 사실이 재확인됐고,
이어서 wiki 저장소 위치·`WIKI_DIR` 설정값을 확인하려다 여러 한계가 드러났다.

**성격: 관찰·확인 세션 (2026-07-08 provider 연동 설계의 후속 상태 점검).**
2026-07-08 설계([[2026-07-08-장기기억-provider-연동-설계]]) 이후에도 어시스턴트 관점에선
memory provider가 여전히 연결되어 있지 않음을 보여준다.

기간: 2026-07-11 16:27~16:32 (KST). 원본: [[raw/conversations/2026-07-11-기억-요약-wiki-경로-확인]]

## 흐름 (시간순, 4왕복)

1. **"기억에 저장된 내용 요약 정리"** — 어시스턴트: "이전 대화 기록·사용자별 저장 기억을 조회·요약할 도구가 없다. 매 요청은 현재 컨텍스트만 기반"이라고 답함. (장기기억 tool 부재 재확인)
2. **"wiki 저장소 위치는 어디?"** — 어시스턴트: 작업 폴더 하위에 `wiki` 디렉터리를 못 찾음. `docs/`·`src/wiki/`·`templates/`·`apps/` 추정만 나열. (john-wiki 저장소를 인지 못 함)
3. **"config에 설정된 WIKI_DIR 현재 값은?"** — 어시스턴트가 `src/config.ts`를 읽어 실제 코드 라인을 인용:
   ```typescript
   wikiDir: process.env.WIKI_DIR ?? path.join(os.homedir(), "Works", "llm-wiki")
   ```
   → 기본값은 `~/Works/llm-wiki` (예: `/Users/progdesigner/Works/llm-wiki`).
4. **"시스템에서 확인하면?"** — 어시스턴트: "접근 가능한 도구는 **파일시스템·git·웹 검색/조회뿐이고 환경변수를 직접 확인하는 기능은 없다**"며 `echo $WIKI_DIR`/`printenv` 등 사용자가 직접 확인할 방법만 안내.

## 핵심 관찰

- **memory provider는 어시스턴트 쪽에서 여전히 미연결** — 2026-07-08 설계 세션에서 제안된 `search/read/list` tool·`AI_CONTEXT.md` 자동 주입이 아직 이 채팅에 노출되지 않음. "기억 요약"을 못 하고, john-wiki 저장소의 존재조차 스스로 찾지 못함. → [[long-term-memory-architecture]]
- **코드엔 `wikiDir` 설정이 이미 존재** — `src/config.ts`에 `wikiDir` 항목과 `WIKI_DIR` env 오버라이드가 들어와 있다. 즉 wiki 연동 배선이 **코드 레벨에선 착수됨**(2026-07-08 "완전 미구현"에서 진전). 다만 tool 노출·조회 경로는 아직 안 붙음.
- **⚠️ 경로 불일치** — `config.ts` 기본값은 `~/Works/**llm-wiki**`인데, 실제 위키 저장소는 `/Users/progdesigner/Works/**john-wiki**`다(karpathy 패턴의 `llm-wiki`에서 이름을 바꾼 흔적). `WIKI_DIR` env로 오버라이드되지 않는 한 하네스는 존재하지 않는 `llm-wiki` 경로를 가리킨다. → [[john-wiki]]
- **이 세션의 tool 셋** — 파일시스템·git·웹만 노출, **bash/쉘·환경변수 조회 없음**. (2026-07-06~09 세션에선 bash가 있었음 — 대화/설정마다 tool 노출이 다르다.)

## 미해결 / 다음 단계

- `config.ts`의 `wikiDir` 기본값을 `john-wiki`로 바로잡거나, `WIKI_DIR=/Users/progdesigner/Works/john-wiki`를 하네스 환경에 설정해야 함.
- `wikiDir` 설정을 실제 조회 tool/컨텍스트 주입까지 연결 — 즉 [[wiki-memory-provider-integration]] 절차의 5~7단계(tool 노출·주입·검증)가 아직 남음.
