# 2026-10-01~03 Edit 템플릿 구조 편집·가이드 이미지·오디오 크로스페이드·파일 복구

`Tool: codex`, `lampas-system` 작업 폴더, 09:12Z 2026-10-01 시작. [[lampas-web-edit]]의 템플릿
구조 편집 화면(`/templates`)을 처음 신설한 뒤 같은 터미널 세션 안에서 20개 가까운 후속 요청이
연속 처리됐고(버전 0.1.46→0.1.55), 환경 컨텍스트가 2026-10-03으로 바뀐 뒤 "파일 없음" 클립 복구
기능(0.1.57)까지 이어졌다 — 캘린더로는 사흘에 걸쳤지만 하나의 이어진 작업 흐름.

## 1. 템플릿 구조 편집 화면 신설 (0.1.46)
"edit에서 템플릿을 설정할 수 있잖아, 그걸 편집할 수 있는 화면으로 따로"라는 요청을 이름·설정값
수준이 아니라 **텍스트·이미지·영상 영역 자체를 추가·삭제하고 위치·크기·레이어 순서를 바꾸는** 구조
편집 요구로 재확인한 뒤 구현. 저장하면 템플릿 레코드가 갱신되고, 이미 그 템플릿으로 편집 중인
영상에는 소급 적용되지 않는다. `edit.lampas.io/templates`로 배포, 템플릿 테스트 15개 신규.

## 2. 영상 영역 가시성 2라운드
"영상 영역이 검은색으로 더 표시되게" → 검정 면 + 흰 라벨로 1차 수정. 이후 "영상 출력 영역이 어디까지인지
구분 안 됨 + Cover/Contain 재설정 + 가운데 `+` 제거" 재지적으로 **출력 캔버스(검정+테두리+해상도
표시)**와 **영상 배치 영역(짙은 회색)**을 색으로 분리하는 2차 수정까지 이어짐.

## 3. 정밀 편집 + 선택 강조 + 잠금 가이드 이미지 (테스트 609개)
한 메시지로 들어온 세 요청 — 이미지·텍스트 1px/10px 단위 이동과 세밀한 크기 조절, 선택 영역에
청록 테두리+모서리 핸들, 그리고 템플릿 위에 올려 위치를 맞추는 용도의 **잠금 가이드 이미지**(투명도·
레이어는 조절 가능하지만 실제 적용·내보내기에선 항상 제외) — 를 함께 구현. 가이드 제외가 저장 후에도
유지되는지 테스트로 고정, 브라우저에서 드래그·선택·투명도·레이어 변경을 직접 검증.

## 4. Cover/Contain 식별 + 트랙 목록 줄바꿈
스크린샷 2장으로 "영상이 Cover/Contain 중 어떻게 배치되는지 안 보인다"와 "텍스트가 넘친다"를 지적.
전자는 미리보기 계산을 최종 렌더와 같은 공식으로 맞춰 해결(이 앱의 "미리보기·렌더 공용 함수" 원칙),
후자는 실제로는 입력란이 아니라 **왼쪽 트랙 목록 항목의 줄바꿈 CSS 누락**이 원인이었음.

## 5. Edit 컴포넌트 통합 + 시스템 폰트 자동 로드 (테스트 616개)
"최대한 Edit 편집 도구랑 비슷하게" + "시스템 폰트도 쓰고, 로딩 시 폰트도 자동으로" 요청 — 템플릿의
텍스트·이미지 도구를 Edit의 실제 컴포넌트로 교체(폰트·굵기·자간·행간·테두리·위치가 동일 UI 공유),
시스템 폰트 사용 설정을 기억해 다음 화면 로딩 시 목록·선택 폰트를 자동 복원하도록 연결. 새로고침 후
자동 복원과 미리보기 반영을 브라우저에서 직접 확인.

## 6. 기울임 버그 + 굵기 세부 입력 + 템플릿 이미지 교체
"기울임 체크해도 적용 안 됨", "굵기 더 디테일하게" 제보 — 원인은 렌더 캔버스가 지원 안 하는 이탤릭
문법을 쓰던 것, 지원 문법으로 교체해 해결. 굵기는 100~900 세부 선택 + 1~1000 숫자 직접 입력,
구글 폰트 지원 굵기 전부 로드로 확장. 같은 배치에서 "템플릿 이미지도 교체할 수 있게" 요청까지
구현 — 배치(위치·크기·투명도·레이어)는 유지한 채 새 파일로 교체.

## 7. 중앙 정렬 가이드라인 포팅 (0.1.52, 테스트 617개)
Edit 에디터 미리보기에 이미 있던 중앙 스냅+점선 가이드를 템플릿 구조 편집 화면에도 포팅. 드래그 시
가로·세로 중앙 가이드 표시+자동 스냅, Alt 키로 자동 정렬 끄고 미세 조정.

## 8. 커스텀 한글 OTF 폰트 굵기 인식 버그 (0.1.53)
사용자가 실사용 중인 한글 폰트 `HGGGOTHICSSI_PRO_00G/20G/40G/60G.OTF`(HG꼬딕씨 Pro) 4개를 첨부해
"제대로 적용 안 된다" 확인 요청. 원인: 파일명 끝 `00g·20g·40g·60g` 굵기 접미사를 로더가 인식하지
못해 네 굵기 전부 보통(400)으로 등록되고 있었음 — 접미사별 구분 적용 + 개별 스타일 직접 선택 기능
추가, 브라우저에서 네 굵기 한글 렌더링을 실제로 비교해 검증.

## 9. 텍스트 테두리 체크박스 (0.1.54)
"테두리 색 앞에 체크표시 넣어서 테두리 제거 기능도" — 테두리 색상 앞에 체크박스 추가, 끄면 테두리
제거·다시 켜면 기존 색 복원. Edit·템플릿 양쪽 텍스트·자막에 모두 적용.

## 10. 저장소 전체 141개 파일 커밋·푸시
"지금까지 작업한 모든 코드를 커밋 후 푸시해줘" — 워킹트리에 섞여 있던 분석 도구·[[lampas-api-mcp]]·
인증·Talk 관련 다른 작업까지 사용자 지시대로 모두 함께 커밋. 첨부파일 Git 제외는 유지. 141개 파일,
커밋 `3da150d4`, `origin/main` 푸시 완료.

## 11. 오디오 크로스페이드 + "이어서 편집" 재진입 버그 (0.1.55)
- **오디오 크로스페이드**: 영상 크로스페이드처럼 오디오도 전환 구간에서 자연스럽게 이어지도록 —
  영상 원음·추가 오디오 트랙 각각에 크로스페이드 길이 설정(영상 '전환' 탭, 오디오 '사운드' 설정),
  미리보기와 출력이 같은 볼륨 곡선을 공유하도록 수정(기존엔 출력에만 일부 연결, 미리보기는 무반응).
- **"이어서 편집" 버튼이 새로고침해야만 이동**: 목록으로 돌아간 뒤에도 그 편집본을 "이미 열려 있음"
  으로 영구히 판단하던 가드가 원인 — 실제로 그 편집본이 지금 화면에 열려 있을 때만 막도록 좁혀
  수정. 재사용 가능한 버그 클래스로 일반화 → [[stale-already-open-guard-blocks-reentry]].

## 12. "파일 없음" 클립 복구 경로 확장 (0.1.57, 2026-10-03)
환경 컨텍스트가 2026-10-03으로 바뀐 뒤 "클립들이 파일없음으로 뜨는데 다운받을 수 있는 기능" 요청.
기존엔 서버 백업(`EditSessionAsset`) 하나에만 의존해 그게 없거나 실패하면 영구히 "파일 없음"으로
남는 구조였음 — 클립 뱅크·영상 소스·저장된 원본 URL까지 포함한 다단계 복구 체인으로 확장하고, 개별
"원본 다시 받기"와 전체 "누락 원본 다시 받기" 버튼을 신설. 복구해도 기존 위치·트림·자막은 유지,
원본 URL·서버 백업이 모두 없는 순수 로컬 파일은 "직접 다시 연결" 안내로 구분. 기존 자동복구 절차의
일반화된 보완 → [[local-asset-fingerprint-s3-backup-recovery]] "단일 백업 소스가 실패하면 영구히
남는 함정" 절 추가.
