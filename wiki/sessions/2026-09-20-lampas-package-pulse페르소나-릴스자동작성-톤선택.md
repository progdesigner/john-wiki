# 2026-09-20 — Lampas Package: Pulse 페르소나 릴스 자동작성 + 문체 톤 5종

`Tool: codex` 세션 (`lampas-system` 저장소, 세션 시작 UTC 2026-09-19T15:26 = KST 2026-09-20
00:26). 하루 안에 기능 구현 → 프롬프트 충돌 진단·수정 → 톤 선택 기능 추가까지 3단계로 이어지고
매 단계마다 배포까지 완료됨.

## 배경

**Package** 앱(`package.lampas.io`, "새 패키지" 화면 `/new`)은 완성된 릴스 영상을 등록해 SNS
채널에 게시하는 도구. 이전까지 위키에는 `[[dalar-web-first]]`·`[[lampas-web-reels]]`에서
"Package 앱(소속 미상)"으로만 언급돼 있었다 — 이 세션으로 정체 확인: `lampas-system` 저장소
소속, `package.lampas.io`에 배포. → 신규 엔티티 [[lampas-web-package]]

## 1단계 — Pulse 페르소나 기반 자동 작성 구현

- 요청: "새 패키지" 화면에 `[[lampas-agent]]` Pulse에서 가져온 페르소나로 릴스 제목·본문을
  자동 작성하고, 해시태그는 별도 영역에서 **최대 5개**까지 추가.
- 구현: 페르소나 선택 UI 연결, 영상의 **대표 장면 3개**를 참고해 제목·본문 생성(장면을 읽을 수
  없으면 사용자가 입력한 힌트로 대체). 해시태그 5개 제한을 새 패키지 화면·릴스/인스타그램 편집
  화면·저장 API 세 군데 모두에 적용. 생성 결과는 저장 후 편집 화면에서도 유지.
- 검증: 빌드·타입체크·테스트 23개 통과(실제 AI 호출·배포는 아직 안 함).
- 사용자가 "배포 안했으면 배포도 해줘"라고 요청 → API(테스트 961개+프로덕션 빌드)·웹 순서로
  배포, 캐시 갱신·신규 파일 제공까지 확인. `https://package.lampas.io/new`에서 사용 가능 안내.

## 2단계 — 페르소나 무시 버그 진단·수정

사용자가 실제 생성 결과("팬들 환호가 이해되는 순간이었어요. 다음 기록도 같이 모아가요" 류
1인칭·감성 캡션)를 페르소나 톤과 다르다고 지적, "다른 프롬프트 설정이 들어가 있는지" 확인 요청.

- **원인 1**: 페르소나를 선택하지 않으면 **"등장인물이 1인칭으로 말하는 일상 캡션"**을 강제하는
  기본 프롬프트가 있었음. 페르소나 선택 시 이 지시는 빠지지만, 페르소나의 말투·금지 표현을
  우선하라는 기준이 약했음.
- **원인 2**: 현재 릴스와 무관한 **다른 영상의 제목·댓글까지 프롬프트에 함께 전달**되고 있어
  근거가 섞임(cross-contamination).
- 수정: 기본 1인칭 캡션 지시 제거, 페르소나의 설명·타겟만 작성 기준으로 삼도록 변경. 상투적
  감성 도입·"같이 모아가요" 식 맺음말 억제. 다른 영상 근거 제외, 확인 안 된 경기 상황 추측 금지.
- 검증: 테스트 961개 통과, API만 재배포(웹 변경 없음). → 절차 패턴은
  [[persona-prompt-default-override-audit]] 스킬로 추출.

## 3단계 — 전문 채널 톤 5종 선택 기능 추가

사용자가 원하는 형식이 페르소나 서사가 아니라 **"전문 채널이 하이라이트를 소개하는 공지형
게시글"**(예: "오늘 경기 주요 장면⚾ / 놓치면 아쉬운 오늘의 하이라이트를 만나보세요! /
[NEXT STREAMING] 샌디에이고 vs 콜로라도 9/15(화) 오전 9:30")에 가깝다고 예시 제시, 페르소나를
유지하면서 SNS 전문 채널에 맞는 **문체 톤**을 선택할 수 있게 해달라고 요청.

- 설계: "전문 채널이 소개" 형태를 기본 템플릿으로, 페르소나는 **채널의 관점·타겟**을 유지하는
  역할로 재배치, 그 위에 별도로 선택 가능한 **톤(문체)** 5종 도입. 경기 일정 등은 제공된 정보가
  있을 때만 포함하도록 **"추가 안내"** 입력 필드 신설.
- 톤 5종:
  1. **전문 채널답게** (기본값) — 공식 채널처럼 정돈된 소개 + 시청 안내
  2. **친근하게** — 팬에게 편하게 건네는 해요체
  3. **생동감 있게** — 짧고 활기찬 소개
  4. **담백하게** — 수식어를 줄인 간결한 안내
  5. **페르소나 말투 그대로** — 페르소나 원래 문체 유지
- 본문 구조: **콘텐츠 소개 → 시청 안내 → 선택한 추가 안내**(일정 등) 순.
- 실제 AI로 검증: 테스트용 야구 페르소나 기준 "전문 채널답게" → "MLB 주요 경기 하이라이트를
  간추렸습니다. 핵심 장면을 릴스에서 확인해 보세요", "친근하게" → "놓친 하이라이트 있으신가요?
  ⚾" — 둘 다 입력한 방송 일정과 줄바꿈 유지 확인.
- 검증: API 테스트 968개, 웹·API 배포 완료, 실제 서비스 반영 확인.
