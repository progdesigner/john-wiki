# First(dalar-web-first) 장면 선택·가격 체계·서버 워커 복구·가상 인물 샘플·초대코드 쿠폰 (2026-09-20~24, codex 도구)

`Tool: codex`(PTY 웹 터미널, → [[lampas-harness]]) 세션. 작업 폴더
`/Users/progdesigner/Works/lampas/lampas-system`. 시작 2026-09-20T13:45:09Z, 환경 컨텍스트가
2026-09-21·22·24로 갱신되며 **4일에 걸쳐 이어진 장기 세션**. 원본:
`raw/conversations/2026-09-20-lampas-first-장면가격체계-샘플영상-초대코드.md`(원 파일명
`a7429896-4558-4ff0-861b-4921a54ff0af.md`).

이 세션이 `[[dalar]]` 제품 라인의 실사용 소비자 제품 **`[[dalar-web-first]]`**("First" — AI
돌잔치 인터뷰 영상 서비스, `first.dalar.ai`)를 이 위키에 처음 상세 노출시킨다. 항목별 상세는
엔티티 페이지 [[dalar-web-first]]에 정리했고, 이 세션 페이지는 진행 흐름과 사용자 요청의
맥락을 시간순으로 남긴다.

## 배경
기존 First는 고정 **12장면** 대본 하나만 사용하는 돌잔치 인터뷰 영상 제작 서비스였다.
[[progdesigner]]가 "대본이 3분짜리라 너무 길다"며 짧은 버전 3종(4·6·8장면)을 추가해 선택할 수
있게 해달라고 요청하며 세션이 시작됨.

## 1. 장면 수 선택·가격·관리자 대본 편집 (2026-09-20)
- 4·6·8·12장면(당시 표현 "콘티") 선택, 기존 대본 기반 각 길이별 대본 생성, 관리자에서 대본
  개별 수정.
- 가격: 제작비 5/10/15/20만원, 실결제(VAT 포함) 5.5/11/16.5/22만원, 크레딧 25,000~100,000
  (내부 회계, 이후 고객 화면에서 숨김).
- 주문마다 대본·가격 스냅샷 저장 → 관리자 수정이 기존 주문에 영향 없음.

## 2. "닫아도 계속된다"는데 실제론 안 됨 → 서버 워커 복구 (2026-09-20)
페이지를 닫아도 서버가 이어서 만든다는 안내와 실제 동작의 괴리를 조사해, 콘티 개요 생성 직전
진행 정보를 덮어쓰는 버그와 재시도 횟수 초기화 여지를 발견·수정. 절차 상세는
[[resumable-worker-checkpoint-resume]] 참고.

## 3. 배포 + 기존 주문 보존 확인 (2026-09-21)
운영 DB의 기존 주문 5건·제공 이력 6건을 백업 후 새 컬럼·테이블만 추가, API 전체 테스트 1,050개
통과 후 API→First→Pay 순 배포. 기존 영상 6개 접근 가능 여부까지 매번 대조하는 패턴이 이 세션
전체에 반복됨.

## 4. 관리자 내비게이션 정리 + 선택 UI를 박스형으로 (2026-09-21)
관리자 상단 메뉴를 "서비스/스튜디오" 두 개로 축소, 홈 버튼→관리홈. 4개 장면 선택지를 라디오에서
줄바꿈 없는 박스형 단일행 UI로 교체.

## 5. "콘티"→"크레딧 표현 제거"→가격 재조정 (2026-09-21)
"5만원 제작 시작"→"4콘티 제작 시작" 버튼 문구, 제작비/부가세 이원 표시, **크레딧 언어 전면 제거**
(사용자 명시 지시: "크레딧 얘기는 전부 제거해줘 헷갈리니까"). API·First 배포, 커밋 `1bc0693a`.

## 6. Jev 기반 순차 실행 강화 (2026-09-21)
"작업을 순서대로 실행하는 걸 Jev를 활용해서 끊김없이" 요청 — 저장된 완료 상태 기준 순차 실행,
서버 재시작 시 저장된 영상 작업 ID로 결과 조회 재개, 오류 시 Jev가 재시도/대기/관리자 확인을
판단(연결 실패 시 기본 복구 규칙 폴백, 접수 불명확 시 관리자 확인 우선). 관리자 재생성도 동일
워커 경로로 통합. 테스트 82개(First)·전체 1,067개 통과 후 배포. → [[jev-typed-classification]]
세 번째 사용처로 기록.

## 7. 장면 간 톤 일관성 문제 진단·수정 (2026-09-21)
"각 콘티마다 이미지 톤이 좀 달라진다" → 첫 컷을 촬영 기준으로 명확히 고정(원본 사진은 인물
확인용으로 분리). 절차 → [[scene-reference-lock-visual-consistency]].

## 8. 가상 인물 4명 + 샘플 영상 4편 제작 (2026-09-21)
한국인 가상 아기 4명(남아 2·여아 2, `image_gen` 스킬 제작, 경로
`apps/dalar-web-first/public/samples/characters/PROMPTS.json`)을 전용 테스트 계정으로 실제
결제→제작 파이프라인에 태워 4·6·8·12장면 샘플 영상 생성. 이 과정에서 6장면 4번째, 8장면 3·6
번째 장면의 **여성 인터뷰어 음성이 남성으로 나오는 버그**를 발견·수정(공통 음성 지시가 장면별
지시보다 우선하도록 변경, 23개 질문 장면 전수 재검사). 8장면 한 컷의 배경 소품 반복 등장 문제는
"기준 장면+직전 장면 두 개만 참고"로 축소해 해결. 완성 길이: 4장면 ≈43초·6장면 ≈1분13초·8장면
≈1분29초·12장면 ≈3분58초. 사용자 지시로 "콘티"→**"장면"** 용어 전환, 12장면="돌잔치 영상의
완성" 카피, 8장면 "추천" 배지 추가.

## 9. First Collection 커버플로우 복원 + 샘플 UX 반복 수정 (2026-09-21~22)
커버플로우 복원(4편 사전 로드, 가운데 무음 자동재생) → 여성 아나운서 버그 재확인 → 가격표 4상자
동일 높이·버튼 하단 정렬·샘플 기본 펼침 → 호버 시 영상이 가려지는 버그 수정+아래 샘플을
썸네일+재생버튼 클릭 즉시재생으로 변경 → 커버플로우 네이티브 컨트롤 숨김(영상만 노출) → 배경
크림색 전환+대기 카드가 맨 뒤로 이동하도록 전환 로직 수정 → 샘플 하단 "샘플 재생" 텍스트 버튼
제거(중앙 재생 아이콘만 유지). 각 단계마다 배포·커밋·푸시(`52207cfd`·`935a0fa2`·`12cdc503`·
`da563921`·`d0b1aa73`).

## 10. 공유(OG) 메타·이미지 (2026-09-21)
1200×630 공유 이미지(로고+크림 배경) 제작, Open Graph/Twitter 메타태그 HTML 직접 삽입, 크롤러
UA로 검증 후 배포(커밋 `d3706b00`).

## 11. 초대코드·상호 쿠폰 시스템 (2026-09-21)
개인 초대코드 → 등록 시 초대자·피초대자 양쪽 50% 할인 쿠폰(1개월 유효, First 전용, 결제당 1장).
자기추천·중복등록 차단, 결제 승인 재시도 시 중복 발급 방지. 실서버 테스트로 할인 후 금액
27,500·55,000·82,500·110,000원 확인, 기존 주문 11건·영상 12건 보존. 관리자
`/rewards`·고객 `/rewards` 연결. 절차 → [[mutual-referral-coupon-pattern]].

## 12. 가격 재조정 — 부가세 포함 정수화 (2026-09-22)
"부가세 포함으로, 5만원으로 딱 떨어지게" → 결제액 자체를 VAT 포함 5/10/15/20만원(정수)으로
재설정, 지급 크레딧은 기존 그대로 유지. 결제 옵션 UI를 줄바꿈 없이 재정리.

## 13. 샘플 4편 추가 제작 + 관리자 샘플 교체 + Package 연동 (2026-09-22)
5만~20만원 구간 샘플을 각 1편씩 재제작(신·구 버전 모두 관리자에서 선택 가능하게), 완성 영상을
"Package" 앱으로 보내 등록하는 기능 추가(초안 저장까지 검증). 8장면 한 컷에 장난감이 등장한
사례는 대본 지시("장난감을 입으로 확인하는")와 일치해 정상으로 판정.

## 14. UI 디테일 수정 + 관리자에서 이전 6장면 재선택 (2026-09-22)
"부가세 포함·추가 금액 없음" 문구 제거+여백 축소. 사용자가 "6장면은 이전께 나은 것 같다"고
문의 → 관리자 샘플 관리에서 이전 버전도 계속 선택 가능함을 확인(완전 교체가 아니라 누적 선택
목록임을 재확인).

## 15. 6장면 인터뷰어 톤 재작업 + 초대코드 사용법 안내 (2026-09-24)
"인터뷰어가 다른 것과 비슷하면 좋겠다, 너무 어색해" → 6장면만 과장된 억양·늘어지는 말끝을 줄여
재생성(다른 세 샘플과 톤 비교), 이전 완성본은 보존. 별도로 초대코드 등록 순서("초대코드 입력
→ Google 로그인") 안내.

## 16. Pay 페이지 분리 (2026-09-24)
`pay.lampas.io` 기본 진입은 크레딧 충전 화면만 표시하도록 복원, First 전용 결제는
`pay.lampas.io/first`로 분리(장면별 제작비+쿠폰, 크레딧 언어 최소화·총 구매액 강조). 기존
`?service=dalar&first=1` 쿼리 진입 경로도 계속 동작.
