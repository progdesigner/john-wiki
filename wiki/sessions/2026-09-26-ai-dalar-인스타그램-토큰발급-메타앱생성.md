# ai.dalar 인스타그램 토큰 발급 — 메타 앱 생성 (2026-09-26)

`Tool: claude` 세션(08:29:35Z 시작, `lampas-system` 작업 디렉터리). `[[progdesigner]]`가
Instagram 계정 **`ai.dalar`**로 직접 게시물을 올릴 수 있도록 전용 Meta 개발자 앱을 만들고 장기
액세스 토큰을 발급받으려 한 세션 — [[lampas-browser]]의 하네스 통합("브라우징" 패널)을 실사용한
초기 사례이자, 그 한계를 드러낸 세션이다. **세션 종료 시점까지 토큰 발급 미완료.**

## 배경 — 왜 `ai.dalar`인가

세션 텍스트만으로는 `ai.dalar`가 `[[dalar]]` 제품 라인의 콘텐츠를 자동 게시하기 위한 전용 계정으로
추정된다. 목표 연결 지점이 `POST /v1/packaging/channels/instagram/connect`(= `[[lampas-web-package]]`
의 SNS 채널 연결 API)라는 점이 이를 뒷받침 — `[[lampas-web-package]]`가 완성된 릴스를 인스타그램에
게시하는 마지막 단계 앱이므로, `ai.dalar`는 그 인스타그램 채널의 실제 계정으로 보인다. 다만 이 세션에서
직접 확인된 사실은 아니라 **추정**으로 남긴다.

## 진행 경과

1. **Meta 앱 생성** — 이름에 "instagram" 사용 불가 확인 → **"dalar ai publisher"**로 명명, 이용 사례
   "Instagram에서 메시지 및 콘텐츠 관리" 선택, 비즈니스 포트폴리오 연결은 생략(테스터 방식이라 불필요).
   앱 ID **1845197946676275**, Instagram 앱 ID **4664045167163943**.
2. **권한 5종 추가**: `instagram_business_basic`, `instagram_business_content_publish`(게시),
   `instagram_business_manage_messages`, `instagram_business_manage_comments`,
   `instagram_business_manage_insights`. 게시 권한 확인 요청(사용자 재확인 질문)에도 이미 추가돼
   있음을 재확인.
3. **`ai.dalar`를 Instagram 테스터로 초대** → `ai.dalar` 계정에서 이메일 인증 코드로 로그인 후 초대
   수락 (IG user ID **17841446605741878**).
4. **개인 계정 → 비즈니스 계정 전환** — `ai.dalar`가 아직 개인 계정이라 프로페셔널 전환 필요, Facebook
   페이지 연결은 "나중에 하기"로 건너뜀(Instagram 로그인 방식은 불필요).
5. **권한 동의 화면에서 전체 권한(게시 포함) 허용** — OAuth 콜백까지는 완료.
6. **장기 토큰 발급에서 막힘** — 아래 "핵심 장애물" 참고. 세션 종료 시점까지 토큰 미확보, 남은 유일한
   경로로 **Instagram 앱 시크릿 코드**를 사용자가 채팅에 직접 붙여넣어 주길 요청하며 종료.

## 핵심 장애물 — 하네스 브라우징 패널의 OAuth 팝업 한계

이 세션이 남긴 가장 재사용 가치 높은 관찰. `[[lampas-browser]]`(하네스 "브라우징" 패널, `apps/browser`)로
Meta 개발자 콘솔을 조작하다 세 가지 구조적 한계에 부딪혔다:

- **비밀번호 필드는 AI 도구가 아예 건드리지 못함** — 브라우저 도구가 비밀번호 입력을 의도적으로 제외.
  Facebook/Instagram 로그인·시크릿 재확인 비밀번호는 항상 사람이 직접 입력해야 함.
- **개발자 콘솔의 "토큰 생성" 팝업이 메인 화면에 토큰을 전달하지 못함** — 정상 브라우저에서는 팝업이
  OAuth 완료 후 스스로 닫히며 메인 창이 완료를 감지하는데, 하네스 브라우저에서는 팝업이 **별도 탭**으로
  열려 닫히지 않아 메인 화면이 완료를 감지하지 못함. 팝업 재시도(콜백 후 AI가 탭을 직접 닫음)로도 해결
  안 됨 → **결론: 이 팝업 기반 토큰 생성 방식은 이 브라우저 환경에서 근본적으로 동작하지 않는다.**
- **앱 시크릿 표시 입력란이 너무 좁아 도구로 읽을 수 없음** — "표시" 클릭 후 값이 좁은 입력란에 잘려
  보이고, `selection`으로 읽기·"복사" 버튼→클립보드(`pbpaste`)로 읽기 모두 시도했으나 실패(클립보드엔
  12바이트 바이너리만 있었음 — 복사 버튼이 실제로 텍스트를 시스템 클립보드에 넣지 않는 것으로 추정).

**대안으로 제시한 확실한 방법**: 시크릿만 확보하면 팝업 UI를 거치지 않고 `curl`로 직접 처리 — 등록된
리디렉션 URL(`https://www.lampas.io/ig-callback`)로 인증 URL을 열어 `code` 수신 →
`api.instagram.com/oauth/access_token`으로 단기 토큰 교환 → `graph.instagram.com/access_token?
grant_type=ig_exchange_token`으로 60일 장기 토큰 교환 → `graph.instagram.com/me`로 계정 검증. 이
경로는 세션 종료 시점까지 시크릿을 못 받아 **실행되지 않았다**.
