### 2026-09-12 — 폴더 선택 버그 + 모바일 방향키 버튼
- **폴더 선택 "not found" 버그**: 원인은 코드 결함이 아니라 **실행 중인 서버가 구버전이라 폴더 조회
  API가 404를 반환**하던 것 — [[self-hosted-agent-server-ops]] 함정 1/함정 4 계열(새 코드는 있지만
  옛 프로세스가 계속 서빙)의 또 다른 사례.
- **모바일 입력창 위 방향키 버튼** — 키보드 위/아래 화살표를 대신할 **↑ / ↓ / Enter / ESC** 네 버튼을
  입력창 위에 추가, 데스크톱에서는 숨김. 실제 터미널에 방향키·Enter·ESC 입력을 보내도록 연결.
- **재시작을 즉시 하지 않고 지연**: 사용자가 "작업이 끝난 뒤 재시작"을 요청 → 당시 **실행 중인 터미널
  세션 3개 + 대기 작업**이 모두 끝나면 자동 재시작하도록 설정 — [[self-hosted-agent-server-ops]]
  함정 2("재시작하면 내 턴이 끊긴다")의 지연·분리 실행 패턴이 **PTY 터미널 세션 개수**를 게이트
  조건으로 쓴 변종. 빌드+테스트 10개+모바일 브라우저 검증 통과.
- **"이 영역은 일단 임시 제거"(프로젝트 영역 숨김)** — 첨부 이미지 기준으로 제목·`＋ 프로젝트`
  버튼·안내 문구 전체를 숨김 처리(마크업은 유지, 나중에 복원 가능). 재시작도 이때 완료 확인(폴더
  조회 API 정상 응답).

### 2026-09-19 — 메뉴 버튼 숨김 + CLI 버전/설치 경로 정리

  확인. 재시작 후 두 수정 파일 커밋·푸시 **`59b3132`**.
- **"codex가 업그레이드 안 된다"** — 원인: 하네스가 전역 설치본이 아니라 **별도 경로의 Codex
  `0.153.4`를 참조**하고 있어 일반 업그레이드 명령이 반영 안 됨. 우선 그 별도 설치본만 배포 버전
  `0.155.1`로 업데이트(새 세션부터 적용, 기존 열린 세션은 실행 당시 버전 유지).

  변경. 이어서 "클로드도 전역을 안 쓰나?" 질문에 **Claude도 `logs/cli-runtime` 아래 별도 설치본을
  참조 중**임을 확인 → 둘 다 이미 있던 전역 설치본(Codex `0.155.1`, Claude `2.1.277`)에 연결하도록
  전환. 실행 중인 세션은 유지, 새 세션부터 적용.
