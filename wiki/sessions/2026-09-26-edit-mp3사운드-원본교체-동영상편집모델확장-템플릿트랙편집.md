## 1. Sound에 mp3 로컬 업로드 추가
기존엔 `music.lampas.io` 게시 트랙만 사운드로 고를 수 있었음. 에셋 패널 사운드 "추가" 픽커 상단에
mp3·m4a·wav·ogg·flac 다중 업로드 영역을 신설, 플레이헤드 위치부터 순서대로 배치. 다른 미디어와
동일한 패턴 재사용: 브라우저 OPFS에 fingerprint 저장(`audio/` 디렉터리), 로그인 시 S3 계정 백업·
타기기 자동 복구, 없으면 "파일 없음"+해당 사운드만 렌더 제외. 신규 `apps/lampas-web-edit/src/lib/localSound.ts`
(순수 로직+테스트). API의 편집 세션 자산 백업 kind에 `audio` 추가.
- 검증: vitest 593개, API jest 26개, tsc·vite build 통과. 배포: `deploy-web.sh lampas-web-edit`,
  `deploy-api.sh lampas-api`, 운영 health 200 확인.
- 커밋 `1692ef53`(기능)·`e4466590`(버전 bump).
- 부수 관찰: 배포 전 루트 `pnpm prisma:generate`가 exit 254로 실패했으나 `deploy-api.sh`의 테스트
  게이트는 영향 없이 정상 통과 — 루트 prisma 커맨드와 배포 스크립트 게이트가 분리되어 있음.

## 2. 에셋(라이브러리 원본) 단위 교체 — "원본 교체"
기존 `replaceClipMedia`(클립 하나만 교체)와 구분되는 새 기능: 라이브러리 원본 파일을 바꾸면 그
원본을 쓰는 모든 클립 인스턴스가 한 번에 바뀜. 에셋 카드 호버 시 ⇄ 교체 버튼(바뀔 클립 개수 툴팁),
타임라인 우클릭 "원본 교체 (같은 원본 클립 모두)" 메뉴 항목 추가. 위치·레이어·전환·자막·화면 맞춤·
팬 키프레임은 유지, 트림 구간은 길이를 지키며 새 원본 범위 안으로 clamp, 이미지↔영상 종류 전환도
지원. 신규 `apps/lampas-web-edit/src/lib/replaceMedia.ts`(순수 로직+테스트)+커맨드 `replaceLibraryMedia`,
단일 클립 교체와 같은 반입 함수를 공유하도록 정리.
- 검증: vitest 603개, tsc 통과. 배포: `deploy-web.sh lampas-web-edit`. 커밋 `e0b4661f`.

## 3. 동영상 편집 노드 모델 8종으로 확장 (기존 3종 + 신규 5종)
사용자가 모델 목록 스크린샷을 첨부하며 "동영상 편집에 쓸 수 있는 모델 모두 넣어줘"로 요청. [[atlas-cloud]]
카탈로그에서 영상 입력을 받아 편집하는 모델을 전부 조사해 레지스트리 하나로 통합:

| 모델 | 크레딧/초 | 입력 길이 | 비고 |
|---|---|---|---|
| xAI Imagine Edit | 50 | ≤8.7s | 기존 |
| Gemini Omni Flash Edit | 140 | ≤30s | 기존 |
| Gemini Omni 1.1 Flash Edit | 41 | ≤10s | 신규, 오디오 포함 |
| Wan 2.7 Video Edit | 100 | 2~10s | 기존, 비율 직접 지정(유일하게 모델이 직접 받음) |
| HappyHorse 1.0 Video Edit | 140 | 3~30s | 신규, 1080p |
| Kling O3 Pro Video Edit | 168 | ≤10s | 신규, 원본 사운드 유지 |
| Kling O3 Std Video Edit | 126 | ≤10s | 신규, 원본 사운드 유지 |
| FLUX 3 Edit Video | 30 | ≤15s | 신규, 동작·타이밍 유지 리렌더 |

Wan 2.7 외 나머지는 서버가 센터 크롭한 뒤 편집. **제외**: Wan 2.6 video-to-video(참조영상으로 새
영상 생성, 출력 5·10초 고정 — 편집과 다른 작업), video-extend·video-upscaler·reference-to-video
계열(편집이 아닌 다른 작업, 필요하면 별도 노드로).
- **구현**: 각 모델의 Atlas 입력 스키마를 실제로 조회해 소스 영상 필드명(`video`/`video_url`)·길이
  상한·비율 지원·기본 옵션을 레지스트리 하나(`lampas-api infrastructure/atlas-cloud/video-edit-models.ts`,
  `dalar-api` 파사드에 동일 파일)에 정리 — 요청 본문 생성·DTO 허용 목록·Transform 길이 캡·크롭
  판정이 모두 이 레지스트리에 위임되어 이후 모델 추가는 한 줄.
  스튜디오 옵션은 **`dalar-web-app`을 먼저 고치고 `pnpm sync:studio`로 `lampas-web-studio`에
  반영** — [[dalar]] 페이지의 "Node Studio SoT는 `dalar-web-app`" 관계가 2026-09-24에 이어 **세
  번째로 실행 확인**된 사례.
- 과금은 generated 카탈로그의 초당 단가 그대로 사용. 배포: `lampas-api`·`dalar-api`·`lampas-web-studio`·
  `dalar-web-app` 4곳, 운영 가격 목록에 신규 5종 노출 확인. 커밋 `bc0e7bff`.
- **가격 드리프트 미해소 메모**: xAI Imagine Edit의 Atlas 정가가 현재 초당 $0.07인데 과금 오버라이드는
  $0.05(50크레딧)로 남아 있음 — `pnpm sync:atlas-pricing` 실행 시 확인 필요(이 세션에서 고치지 않음).

## 4. 템플릿 트랙 추가/삭제 + 에디터 텍스트 트랙 이동·삭제 버그 수정
템플릿 구조 편집(`/templates`) 좌상단 버튼이 "텍스트 트랙 +"·"영상 트랙 +"·"이미지 트랙 +"(파일
선택)로 바뀌고, 트랙 행마다 ↑↓ 순서 이동 옆에 ✕ 삭제 버튼 추가(확인 후 트랙 내 항목도 함께 삭제,
같은 종류 트랙 번호를 당겨 공백 방지). 순서·삭제 로직은 `lib/templateTracks.ts` 순수 함수로 분리+테스트.

에디터 타임라인에서는 텍스트 블록 우클릭 메뉴 자체가 없어 "삭제가 안 된다"는 제보로 이어졌던
것으로 확인 — 실제로는 기능이 아니라 진입점이 없었던 것. 우클릭 메뉴에 "위 트랙으로 이동"(맨 위면
새 텍스트 트랙 생성 후 이동)·"아래 트랙으로 이동"·"텍스트 삭제" 추가, 겹침으로 이동 불가 시 토스트
안내. 삭제는 우클릭 메뉴·인스펙터 "삭제" 버튼·Delete 키 세 경로 모두 동작 확인. 잠긴 트랙의 텍스트는
메뉴가 열리지 않음(트랙 잠금 해제 필요).
- 검증: vitest 633개, tsc, vite build 통과. 배포: `deploy-web.sh lampas-web-edit`. 커밋 `1223e67f`.
- **운영 메모**: 워킹트리에 다른 세션([[lampas-web-spot]] 관련으로 추정)의 미관련 변경이 남아있어
  자기 경로만 선택 커밋 → [[selective-hunk-commit-shared-file]] 패턴과 동일한 상황(이번엔 파일 단위
  선택, 헝크 단위는 아님).
