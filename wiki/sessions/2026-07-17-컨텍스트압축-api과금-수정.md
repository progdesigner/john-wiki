# 2026-07-17 — 컨텍스트 압축(`/compact`)이 API 과금으로 빠지던 버그 수정

## 요청
"컨텍스트 압축 기능도 API로 말고 크루드 토큰으로 할 수 있게 수정해봐" — [[lampas-harness]]의 `/compact`(컨텍스트 압축)가 Claude Code 구독(OAuth) 토큰이 아니라 API 종량 과금으로 도는 것을 고쳐달라는 요청.

## 조사 결과
- 컨텍스트 압축은 Anthropic API를 직접 호출하지 않는다 — `@anthropic-ai/claude-agent-sdk`의 `query({ prompt: "/compact", ... })`로 동작한다(`src/server.ts`의 `compactClaudeSession()`, line 2460~2515).
- 원인: `compactClaudeSession`의 `query()` 호출(line 2470-2479)에 **`options.env`가 없어서** 서브프로세스가 `process.env`를 그대로 상속받고, `ANTHROPIC_API_KEY`가 있으면 SDK가 OAuth보다 그걸 우선한다. 이 키는 크레딧 0이라 압축이 실패하고 있었다.
- 대조: 채팅 라이브 세션(`server.ts` line 2028-2033)과 큐 잡 러너(`runner.ts` line 50-58)는 둘 다 `claudeAuthEnv()`(또는 동등 로직)로 `env`에서 `ANTHROPIC_API_KEY`를 지워 OAuth로 강제한다. **압축(`compactClaudeSession`)만 이 처리가 빠진 세 번째 진입점**이었다.
- 참고로 오해하기 쉬운 실제 직접 API 호출 코드 2곳(`claudeModelsLive`의 모델 목록 조회 line 486, `judgeTierClaude()`의 자동 티어 판정 line 579-596)이 있지만 이 둘은 압축과 무관.

## 수정
`src/server.ts`의 `compactClaudeSession`에 채팅 라이브 세션과 동일한 규칙 적용:
```ts
env: claudeAuthEnv(session.live?.apiBilling ?? false),
```
`npm run build:server`(tsc) 통과 확인. **반영하려면 데몬 재시작 필요**(`launchctl kickstart -k gui/$(id -u)/io.lampas.harness`) — 재시작은 사용자가 직접 하기로 함(제 턴 안에서 8787을 kill하면 출력·권한 채널이 끊기므로).

## 스킬로 남김
사용자가 "이 사례를 스킬로 남겨달라"고 요청(처음엔 "내일 숙제"로 응답했다가 정정 — 아래 [[#피드백]] 참고) → [[sdk-claude-code-vs-api-billing]] 스킬에 `compactClaudeSession`을 **세 번째 확인된 누락 진입점** 사례로 추가. "SDK 호출 진입점마다 개별 확인해야 한다"는 기존 교훈([[runner.ts]] 사례)의 두 번째 실증.

세션은 사용자가 다음 단계("토큰으로도 압축될 수 있냐"는 질문에 대한 스킬 작성) 도중 중지시켜 끝났다.

## 피드백
사용자가 "숙제를 남겨달라"고 한 요청을 어시스턴트가 "내일 다시 질문에 답하겠다"는 리마인더로 잘못 해석했다가, 사용자가 "숙제가 아니라 스킬로 남겨달라는 거였다"고 정정함. → **"숙제로 남겨줘" = 다음 대화를 위한 리마인더가 아니라 위키 스킬 페이지에 기록해달라는 뜻으로 해석할 것.**
