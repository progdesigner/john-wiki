# 2026-09-27 — Fit·Spot Threads 홍보 문구 작성 + Spot 메타(OG) 이미지 적용·재배포

`Tool: codex` 세션(2026-09-27T08:08Z 시작, 작업폴더 `lampas-system`). 짧은 요청 5개로 끝난 가벼운
운영 세션. [[progdesigner]]가 `fit.lampas.io`·`spot.lampas.io` 홍보용 Threads 글을 요청하고, 이어서
Spot에도 Fit과 같은 공유 메타 이미지를 적용·배포시켰다.

## 1~3. `fit.lampas.io` Threads 문구 — 3회 반복
- 1차: "스크롤하는 1분 vs 플랭크하는 1분" 대비로 시작하는 일반 홍보 문구, 링크 포함.
- 2차 요청("운동 하는 사람 특히 여성 타겟으로, 여성을 언급 없이"): 타겟을 운동 루틴에 플랭크 1분을
  끼워넣는 사람으로 좁히되 성별 단어는 전혀 쓰지 않고 "운동 끝나고 한 세트, 홈트 시작 전에 한 세트"
  식 사용 시나리오로 암시.
- 3차 요청("요즘 유행하는 챌린지를 만들었다고"): 1·2차의 개인적 공감형 도입을 버리고 "요즘 유행하는
  플랭크 챌린지를 웹사이트로 만들었다"는 제작자 공개형 문구로 재작성.
- 세 버전 모두 핵심 정보(음악 12초마다 동작 전환·앱설치·회원가입 불필요·1분 완성)는 유지한 채
  도입부 톤·타겟 프레이밍만 바꾼 점이 특징 — 반복 재작성 요청에서 반복 유지되는 요소가 무엇인지
  보여주는 사례.

## 4. `spot.lampas.io` Threads 문구 — 신규 작성
"이번 주말에 어디서 먹지" 공감형 도입 + 지도에서 맛집 둘러보기·즐겨찾기 기능 소개. Fit과 같은 짧은
훅+기능 2~3줄+CTA+링크 구조를 그대로 재사용.

## 5. Spot에 Fit과 같은 공유(OG) 이미지 적용 + 재배포
- [[lampas-web-fit]]이 이미 갖춘 4:3 비율 OG 이미지(동작 클립 프레임 기반, 2026-09-26 "메타데이터/SEO"
  작업분)를 참고점으로 Spot용 공유 이미지를 신규 제작.
- 내장 `imagegen` 스킬로 Spot의 파란 톤 + 음식·지도 이미지를 조합해 4:3 이미지 생성, 공유 문구
  "오늘, 어디서 먹을까?" 적용. 산출물: `apps/lampas-web-spot/public/og-spot-4x3-20260927.png` ·
  프롬프트 `output/imagegen/spot-og-prompt.txt`.
- OG·Twitter 메타 태그에 연결 → 빌드·업로드 → 테스트 14개 통과 → 배포 후 운영 URL
  (`https://spot.lampas.io/og-spot-4x3-20260927.png`)에서 이미지 응답 직접 확인.
- 사용자가 "메타 이미지도 적용해줘야지"라고 재차 요청한 것은 1차 배포 보고에서 메타 태그 반영
  여부가 충분히 전달되지 않았기 때문으로 보임(실제로는 1차 응답에 이미 OG·Twitter 태그 적용이
  포함돼 있었음) — 2차 응답에서 "서버에 업로드하고 `og:image`에 연결한 상태"라고 재확인하고,
  스레드에 남은 구버전 미리보기 캐시 문제 대응으로 `?share=20260927` 캐시버스팅 쿼리 링크를 제안.
