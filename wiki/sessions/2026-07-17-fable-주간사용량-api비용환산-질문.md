## 왜 기록해두는가

이 질문은 두 기존 토픽이 만나는 지점이다:
- [[claude-model-pricing]] — Fable 5 API 단가($10/$50, 1M 토큰당, 2026-07-13 기준)가 이미 있어
  "1% 사용량 = 몇 토큰 = 몇 달러" 계산의 재료는 갖춰져 있다.
- [[sdk-claude-code-vs-api-billing]] — 구독 모드의 `seven_day` rate limit(주간 사용량 %)을
  실측하는 SDK 훅(`usage_EXPERIMENTAL...()`, `rate_limit_event`)은 이미 문서화돼 있으나
  [[lampas-harness]]엔 **미구현**이라고 기록돼 있음(2026-07-15 재확인).

즉 이 질문에 제대로 답하려면 "주간 한도 100%가 실제 토큰/비용으로 얼마인가"라는 환산 기준이
필요한데, 그 기준값(예: Max 플랜 주간 한도의 토큰 환산)이 현재 위키 어디에도 없다. 다음에 같은
질문이 나오면 먼저 [[claude-model-pricing]]과 [[sdk-claude-code-vs-api-billing]]을 확인하고,
Anthropic 구독 한도 산정 기준(공개돼 있다면)을 조사해 답할 것 — 이번 세션은 근거 없이 답을
추정하지 않고 미답변 상태로만 기록한다.
