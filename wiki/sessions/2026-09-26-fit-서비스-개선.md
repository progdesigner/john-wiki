# Fit 서비스 개선 (2026-09-26, `Tool: claude`)

`Tool: claude` 세션(터미널, 작업 폴더 `/Users/progdesigner/Works/lampas/lampas-system`). 제목
"Fit 서비스 개선". [[2026-09-25-lampas-web-fit-구축-배포]](codex 도구, 합성 비트 음악으로 최초
구축)의 바로 다음 반복 세션으로, [[progdesigner]]가 유튜브 쇼츠 1건을 기준점 삼아 첨부 파일(mp3·
webm·이미지)을 턴마다 보내며 `fit.lampas.io`("1분 플랭크 챌린지")를 왕복 다듬었다. 아주 긴
세션으로 커밋만 15개 이상(f66b6803 ~ 8a2b64fa). 상세는 신설 엔티티 [[lampas-web-fit]]에 정리.

## 핵심 변경 (시간순)
1. **합성 루프 → 실제 음원**: 첨부 mp3(Deti Rave, 160 BPM·152박·57초)를 분석해 Fast Climbers→
   Plank Jacks→Side Taps→Cross Taps→Fast Climbers 5동작에 박 배분, Web Audio 공유 시계로 음악·
   타이머 동기화.
2. **1분 재설계 + 동작 영상화**: 5동작을 각 32박(12초)×5=160박=정확히 1분으로 재설계, 반복 요청
   받은 첫 동작(Fast Climbers)에 투명 webm 루프 영상 적용. 나레이션·비트카운트 제거.
3. **전동작 영상화 + 알파 폴백**: 4개 동작 영상 전부 연결, 투명 webm을 못 그리는 브라우저(Safari
   계열)에서는 캔버스로 첫 프레임 알파 검사 후 동작 영역 전체를 검정으로 자동 전환.
4. **사이드바 제거·1분 챌린지 전용 사이트로 축소**: 루틴 선택·템포·라운드·합성음악·코치팁 전부
   제거, 플레이어 중앙 한 줄 배치로 집중 구성.
5. **오늘의 루틴 카드 클릭 → 플레이어 미리보기** 연동 (`stagedMove` 순수 로직).
6. **영상 확대**(겹침 허용), **메타데이터·SEO**(OG 이미지, 매니페스트, JSON-LD) + "AI 티 줄이기"
   (Claude 아티팩트 디자인 가이드 원칙 적용 — 영문 대문자 라벨 제거, 장식 배지 제거, 숫자 표기
   한국어화).
7. **디자인 톤 전환 2회**: 다크 네온 → 밝은 모노톤 피트니스 센터 → 사용자 피드백으로 영상 영역만
   다시 차콜 톤으로 롤백(페이지 나머지는 밝은 모노톤 유지).
8. **벡터 캐릭터 완전 삭제** (영상 실패 시 빈 무대 + 동작 이름 텍스트만).
9. **배경 이미지 실험**: 매트 스튜디오 사진 추가 → 모바일 Safari용 HEVC 알파 `.mov` 추가 생성(VP9
   webm은 Safari에서 불투명 디코딩됨, 첫 프레임 알파 검사로 자동 선택) → 사용자가 배경 이미지만
   롤백 요청, HEVC 자동선택 로직은 유지.
10. **원격 머지 + 영상 재교체 + 푸시**: 다른 세션이 올린 원격 커밋(유튜브 패키징 등)과 머지,
    package.json 버전 충돌만 해결.
11. **ElevenLabs 코치 음성 도입**: 'Domi' 프리셋 여성 보이스로 준비 카운트·전환 예고·완료 멘트
    15문장 사전 녹음, Web Audio 같은 시계로 박 단위 예약. 마이크 토글 UI 추가.
12. **완료 멘트 잘림 버그 수정**: 음악 소스 종료 시점에 오디오 컨텍스트를 바로 닫아 동시 시작하는
    마지막 멘트가 잘리던 버그 → 모든 소스 종료 후 닫도록 수정. → [[web-audio-context-close-after-last-source]]

## 검증 패턴
매 변경마다 vitest(최종 22개)·빌드·헤드리스 Chromium(Playwright) 실행으로 전환 시각(설계값과
10ms~수백ms 이내 일치)·콘솔 오류·시각 요소를 확인한 뒤 `deploy-web.sh lampas-web-fit`으로 배포,
운영 200 응답 확인 후 커밋하는 루틴을 일관되게 반복 — "배포 전 헤드리스 브라우저 실제 재생 검증"
패턴.

## 참고 / 이상 정황
- 한 사용자 턴(메타데이터·디자인 개선 요청 직후)에 **Claude Artifact 도구의 "Page contract"/디자인
  가이드 전문**이 사용자 메시지 형태로 그대로 로그에 기록돼 있음 — 실제로는 하네스가 로드한 스킬
  문서가 사용자 턴으로 잘못 기록된 것으로 보이나(내용 자체가 람파스 서비스와 무관한 범용 Artifact
  퍼블리시 규칙), 원인 조사는 이 ingest 범위 밖. [[chat-archive-duplication-anomaly]]와 유사한
  로그 무결성 이상 계열일 가능성이 있으나 패턴이 달라(스킬 문서 통째 삽입) 별도 기록만 남김.
- 트랙 아티스트 표기 "URYL"은 파일명에서 추정한 값이라 부정확할 수 있음(`lib/workout.ts` `tracks`).
- 크로스 탭 동작 영상만 30초 원본(7.2MB, .mov 변환 시 18MB→5.8MB 품질 하향)이라 다른 1.5~2초
  루프 셋보다 무겁고 루프 지점이 매끄럽지 않음 — 루프 버전 미제공으로 미해결.
