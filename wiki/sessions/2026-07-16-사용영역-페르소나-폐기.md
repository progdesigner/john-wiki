# 2026-07-16 — "사용 영역" 페르소나 기능 전면 폐기

`[[lampas-harness]]` 웹 채팅, 2026-07-16 04:26:37~04:32:54Z. 1왕복(조사 + 구현) 세션.
**이 세션이 이후 [[2026-07-16-잔여작업커밋-원격머지-재시작요청]]에서 커밋된 `7b27897`
("refactor: presets 폴더 제거 및 서버 로직 정리")을 실제로 만든 원본 작업 세션이다** — 그
세션에는 "presets 폴더 삭제"라는 결과만 기록돼 있었는데, 여기서 무엇을·왜·어떻게 지웠는지
전체 경위가 확인된다.

## 요청
> "사용영역을 일반과 이미지로만 나누고 다른 영역은 숨김처리해주고 설정에서도 사용영역
> 페르소나를 제거하고 페르소나를 이제 사용하지 마"

두 가지가 섞인 요청: (1) UI 메뉴는 일반/이미지 2개만 남기고 나머지 숨김, (2) 페르소나
*기능 자체*(설정 화면 편집 UI + 백엔드 주입 로직)를 완전히 폐기.

## 1단계 — 조사 (병렬 에이전트로 아키텍처 전수 파악)
기존 `[[use-area-personas]]` 토픽 페이지가 2026-07-08~09 시점의 설계만 기록하고 있었는데,
이 세션에서 **실제 구현 상태를 file:line 단위로 재확인**했다:

- **프론트 UI**: `apps/web/index.html`(Vite 소스, 현재 서빙본) — 좌측 `#catbar` 메뉴
  (`renderCats()`, 1242~1251행), `CATEGORIES` 배열(1220~1234행, 6개 영역: 일반/비즈니스/
  브랜딩/마케팅/이미지/영상), 설정(⚙) 화면의 "사용 영역 페르소나" 편집 섹션(476~486행:
  `presetSel`/`presetText`/저장·초기화 버튼). 동일 로직이 레거시 `public/index.html`에도
  수동 이식된 채 존재(서버가 `apps/web/dist` 없을 때만 폴백 서빙). **`apps/web/public/quick.html`
  (퀵챗)에는 이 기능이 아예 없음**.
- **백엔드**: `src/server.ts` — `DEFAULT_PRESETS`(278~341행, 영역별 라벨+프롬프트),
  `presetInstruction()`(365~368행, `presets/<id>.md` 우선·없으면 코드 기본값 폴백), 주입 지점
  **3곳**: Claude Code SDK 경로(2144~2159행 `systemPrompt.append`), 로컬/OpenAI 호환 경로
  (2879·2962행 `baseSystem`), Gemini 경로(3210행 `systemInstruction`). `GET/POST /api/presets`
  (3668~3698행)가 설정 화면 조회/수정/초기화를 담당.
- **저장소**: `presets/*.md`(영역별 6개 파일, git 관리) + `presets/README.md`.
- **`src/runner.ts`(큐 잡 실행기)는 이 로직과 무관** — 고정 `preset: "claude_code"`(Claude Code
  SDK 내장 프리셋, 사용영역 페르소나와 이름만 같고 다른 개념)만 씀.
- **결론**: "영역" 값은 백엔드에서 **오직 시스템 프롬프트 주입 + 상주 세션 재사용 여부 판단**
  (`live.preset !== opts.preset`이면 세션 재생성)에만 쓰이고, 이미지 생성 도구 노출 등 다른
  기능 게이팅과는 무관(이미지 생성은 `OPENAI_API_KEY`/`GOOGLE_API_KEY` 존재로만 게이팅).
- **`apps/web`와 `public/index.html`은 빌드로 연결 안 된 완전히 별개의 수동 관리 사본**
  (2647줄 vs 1930줄, 다수 신규 기능이 `apps/web`에만 있음) — 두 파일을 각각 손으로 고쳐야
  한다는 것도 이 조사에서 재확인.

## 2단계 — 구현
- **프론트 메뉴 축소**: `apps/web/index.html`·`public/index.html` 양쪽 `CATEGORIES` 배열을
  일반/이미지 2개로 축소(비즈니스·브랜딩·마케팅·영상 제거). 이미지 영역은 화질·비율 툴바
  (`imgTools`) 노출용으로 계속 필요해 유지.
- **설정 화면 UI 제거**: "사용 영역 페르소나" select/textarea/저장/초기화 섹션 전체 삭제(양쪽
  파일).
- **백엔드 페르소나 로직 완전 삭제**: `src/server.ts`에서 `DEFAULT_PRESETS`, `presetInstruction()`
  등 페르소나 주입 함수·상수 제거, Claude/로컬·OpenAI 호환/Gemini **3개 경로 모두**에서
  주입 호출 제거, `GET/POST /api/presets` 라우트 삭제.
- **저장소 정리**: `presets/*.md`(6개) `git rm`으로 삭제 — **이 삭제가 나중에 커밋
  `7b27897`로 묶인다**([[2026-07-16-잔여작업커밋-원격머지-재시작요청]] 09:07 세션에서 확인,
  커밋 메시지 "refactor: presets 폴더 제거 및 서버 로직 정리"가 정확히 이 세션의 작업 내용).
- **검증**: 잔여 참조 grep(양쪽 HTML·server.ts) 후 없음 확인, `apps/web` 재빌드(`dist/index.html`
  반영), 백엔드 `tsc --noEmit` 통과.
- **미실행**: 실제 배포 데몬은 재시작 안 함(안전상 어시스턴트가 직접 재시작하지 않음,
  [[self-hosted-agent-server-ops]] 관례) — 이 세션 시점엔 커밋도 아직 안 함(커밋은
  ~2.5시간 뒤 09:07 세션에서 `7b27897`로 이뤄짐).

## 결과 상태 (이 세션 종료 시점)
- "사용 영역" 메뉴: 일반/이미지 2개만 노출(작업 트리에만 반영, 커밋·배포 전).
- 페르소나 시스템 프롬프트 주입: 3개 경로 모두에서 제거 — 일반/이미지 어느 쪽을 선택해도
  이제 시스템 프롬프트에 영향 없음. `preset: currentCat` 값 자체는 여전히 서버로 전송되지만
  백엔드가 무시.
- `presets/` 디렉터리·`/api/presets` API: 완전 삭제.
