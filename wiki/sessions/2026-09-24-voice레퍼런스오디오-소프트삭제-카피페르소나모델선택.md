## 1) voice.lampas.io 레퍼런스 오디오 업로드 (신규 앱 `[[lampas-web-voice]]` 첫 노출)
"가능한 모델만 오디오 파일을 올려서 생성 가능하게 해줘" 요청. 카탈로그 조사 결과 오디오 클론을
받는 모델은 **Seed Audio 1.0 하나뿐**(나머지 xAI·[[gemini]]·[[elevenlabs]]는 프리셋 보이스)임을
확인 → 모델마다 `acceptsReferenceAudio` 플래그 추가, `POST /v1/voice/reference-audio` 신설(S3
저장, 20MB 이하, 과금 없음), 미지원 모델엔 서버가 400으로 거부. 웹은 모델 카드 배지 + Seed Audio
선택 시 업로드 UI 노출, 우선순위 파일→URL→자동 캐논 샘플. API jest 35건·웹 vitest 17건 통과,
lampas-api 0.1.138·lampas-web-voice 배포까지 완료(사용자가 "배포 했어?"로 재확인 요청해 진행).
상세 → [[lampas-web-voice]].

## 2) 생성 내역 삭제 — 소프트 삭제 (다음날)
"생성 내역을 삭제할 수도 있게 해줘" → `voice_generations.deletedAt` 컬럼 신설(수동 DDL, 운영 RDS
API 배포 전 선적용 → [[prod-ddl-before-deploy-with-drift-check]]), `DELETE
/v1/voice/generations/:id`가 소유 행만 소프트 삭제(S3 오디오는 보존), 웹 카드에 삭제 버튼+확인창.
API 37건·웹 17건 통과, lampas-api 0.1.139 배포. **이 세션에서 "배포까지 하면 항상 커밋" 규칙을
메모리에 저장** — 어제 레퍼런스 오디오 작업과 오늘 삭제 기능을 한 커밋(`e3f96b53`)으로 묶고 배포
스크립트의 버전 범프는 별도 커밋(`2230d2b7`)으로 분리, 세션 이전부터 있던 무관한
`lampas-web-voice/index.html` 변경은 제외. 푸시는 안 함.

## 4) 카피·채점·페르소나 생성 모델 선택 기능 (`[[lampas-web-copy]]`·`[[lampas-web-pulse]]`)
"페르소나와 카피 만들때 모델도 선택할 수 있게 해주고, 평가도 모델 선택할 수 있게 해줘" 요청.
- **API 0.1.142**: `GET /v1/copy/models`가 기본 모델 + 고를 수 있는 `options`(GPT-6 Astra, GPT-5.6
  Sol, Claude Opus 5, Claude Sonnet 5, Gemini 3.5 Flash, Gemini 3.1 Pro, Grok 4.5) 반환. 카피
  생성(`POST /v1/copy/runs`)·채점(`POST /runs/:id/score`)이 `model`을, 페르소나 생성(`POST
  /v1/pulse/personas`)이 `model`+`reviewModel`을 받음. 목록 밖이라도 게이트웨이 카탈로그의 LLM이면
  허용, 그 외는 LLM 호출 전 400. 고른 모델이 실패하면 같은 종류의 기본값으로 한 번 재시도, 실제
  쓰인 모델은 결과에 기록.
- **웹**: Copy 스튜디오에 생성·채점 모델 셀렉트(같은 벤더면 "교차 채점 아님" 경고), Pulse
  페르소나 라이브러리에 생성·교차심사 모델 셀렉트. localStorage에 저장, 목록에 없는 옛 값은
  기본값으로 폴백.
- 도중 배치 스크립트가 잘못된 카운트 체크로 중단 → 재확인 결과 4곳 호출부가 맞았음을 확인 후
  재실행. 기존 테스트 하나가 인자 개수를 정확히 세던 assertion이라 다섯 번째 인자 `undefined` 기대로
  수정.
- 검증: API jest 68건, copy vitest 36건, pulse vitest 32건, 배포 게이트 전체 1149건 통과. 운영
  `GET /v1/copy/models`가 실제 7개 options 반환 확인.
- 커밋 `24b12b04`(작업+버전 범프 묶음, 미푸시). **주의**: 작업 트리에 이미 있던 `ai.service.ts`
  수정·미추적 `ai-media-storage.spec.ts`는 이 작업이 아니라 커밋에서 뺐지만, 배포 스크립트가 트리
  전체를 빌드해 이번 API 배포엔 같이 올라감 — 의도한 변경인지 확인 필요하다고 사용자에게 명시적으로
  보고.
