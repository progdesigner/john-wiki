# 2026-07-08 — 장기기억(john-wiki) provider 연동 설계 세션

`[[progdesigner]]`가 일반 Lampas 채팅에서 "내가 지금까지 이걸로 어떤 작업들을 해왔지?"라고 물으며 시작된 세션.
어시스턴트가 **과거 작업 이력·장기기억에 접근할 도구가 없다**는 사실이 드러났고, 이를 계기로
`[[john-wiki]]`를 `[[lampas-harness]]`에 **장기기억 provider로 연동하는 설계**를 도출했다.

**성격: 설계·제안 세션 (미구현).** 당시 어시스턴트에게는 파일/쉘 도구가 없어 실제 코드 변경·커밋은 하지 못했고,
아키텍처·인터페이스·tool schema·테스트 절차를 문서 형태로 제안하는 데 그쳤다.

기간: 2026-07-08 20:14 ~ 20:19 (KST). 원본: [[raw/conversations/2026-07-08-장기기억-john-wiki-연동]]

> **메타 노트**: 이 세션이 제안한 "john-wiki = 실제 장기기억 저장소, LLM이 검색/읽기로 조회" 구조가
> 바로 지금 이 위키가 실현하는 것이다. 이 페이지의 존재 자체가 제안의 실현이다.

## 흐름 (시간순)

1. **문제 발견** — 사용자가 과거 작업을 물음. 어시스턴트는 "이전 세션·다른 대화 기록에 접근할 수 없다"고 답함.
2. **"장기기억을 봐봐" / "john-wiki가 장기기억이야"** — 사용자가 재차 요청했으나, 어시스턴트에게 `john-wiki`를 열람/검색/조회할 도구가 노출되어 있지 않아 여전히 접근 불가.
3. **"기억에 저장 아이콘은 무용지물이냐, 잘 쓸 방법을 찾아라"** — 어시스턴트가 저장/조회 분리 진단 + 활용 전략 제시.
4. **"lampas-harness에 반영해서 기능을 업데이트하라"** — 어시스턴트가 memory provider 연동 전체 설계를 코드 스케치와 함께 제안(직접 수정은 불가).

## 핵심 진단

- **문제는 "저장"이 아니라 "조회 연결"** — "기억에 저장" UI 아이콘으로 저장은 되지만, 저장된 내용이 어시스턴트 컨텍스트로 다시 **주입되거나 검색 가능한지**가 관건. 현 환경에선 후자가 끊겨 있음.
- **테스트로 확인 가능** — 고유 문장("파란 고래는 화요일에 커피를 마신다")을 저장 후 새 대화에서 질문 → 답하면 주입 O, 모르면 주입 X. 관찰상 후자.

## 핵심 결정·제안사항

- **역할 분리** — "기억에 저장" 아이콘 = 안 변하는 **선호·규칙**(짧게), `[[john-wiki]]` = 실제 **장기 작업 이력·프로젝트 기록**(김). 긴 이력은 아이콘에 넣지 않는다.
- **`AI_CONTEXT.md` 자동 주입** — `john-wiki` 루트에 AI용 요약 페이지를 두고 대화 시작 시 system/developer 메시지로 주입. (사용자 선호, 장기기억 구조, 주요 프로젝트, 답변 규칙)
- **memory provider 인터페이스** — `MemoryProvider` ABC(`status`/`read_context`/`search`/`read`/`list_pages`) + `JohnWikiMemoryProvider` 구현(rglob md/txt, 토큰 카운트 스코어링, 발췌). → 상세·함정: [[wiki-memory-provider-integration]]
- **검색 tool 노출** — `john_wiki_status` / `search_john_wiki` / `read_john_wiki` / `list_john_wiki_pages`를 function calling tool로 등록, dispatcher 연결.
- **모델 지침** — "과거 작업/장기기억을 물으면 tool로 조회, 없으면 접근 불가라 명시, **절대 이력을 지어내지 말 것**".
- **환경변수** — `LAMPAS_MEMORY_PROVIDER=john_wiki`, `JOHN_WIKI_ROOT`, `JOHN_WIKI_CONTEXT_FILE`, `JOHN_WIKI_MAX_CONTEXT_CHARS`, `JOHN_WIKI_SEARCH_TOP_K`.

## 제안된 저장소 운용 (역할표)

| 용도 | 저장 위치 |
|---|---|
| 고정 선호·답변 스타일 | 기억에 저장 아이콘 |
| 프로젝트 전체 기록·긴 로그 | `[[john-wiki]]` |
| AI에게 매번 주입할 요약 | `john-wiki/AI_CONTEXT.md` |
| 현재 대화에서만 필요한 자료 | 채팅에 직접 붙여넣기 |
| 검색 기반 장기기억 연결부 | `[[lampas-harness]]`의 memory provider tool |

## 미해결 / 다음 단계

- 설계는 Python(OpenAI-style function calling) 기준 스케치. 실제 `[[lampas-harness]]`는 **TypeScript + Claude Agent SDK**라 그대로는 이식 불가 — 언어/SDK에 맞게 재작성 필요. (모순 아님, 예시 코드일 뿐)
- 제안된 `_safe_path` 경로 가드에 prefix 매칭 취약점 있음 → [[wiki-memory-provider-integration]]의 함정 참고.
- 어시스턴트가 "PR 형태 diff 패치"로 재정리해주겠다고 제안한 지점에서 종료.
