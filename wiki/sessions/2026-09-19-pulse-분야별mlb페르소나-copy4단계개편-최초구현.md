## 요청
"Pulse 기능을 고도화해줘: 유튜브에서 한국 최신 MLB 영상을 검색해 인기 영상을 수집하고, 그걸로
카피 문구의 페르소나를 만들고, 그 페르소나를 Copy에서 선택해 카피를 만들 수 있게 해줘. 페르소나는
클립별로 만드는 게 아니라 **분야별로** 잘 만들어진 것을 만들고, 타겟 규모를 예측하고, 그 페르소나에
맞춰 카피를 만들도록 Copy도 개편해줘. 흐름: **분야 선택 → 클립 선택 → 페르소나 선택(또는 임의
생성 요청) → 페르소나별 카피 생성**."

## 구현
- **한국어 최신 MLB 인기 영상 수집**: 실제 YouTube 검색 API로 최근 30일·한국어 제목·분야 일치
  여부를 걸러 일평균 조회수로 선별. 실 검색 결과에서 20개를 선정해 로컬 DB에 저장(표본 누적 조회수
  약 124만 회).
- **분야별 페르소나 라이브러리**: 클립마다 새로 만들지 않고 **분야 단위로 재사용**하는 기본
  페르소나 세트 + 사용자가 원하는 설명으로 추가하는 커스텀 페르소나를 별도 저장하는 API 신설.
  영상의 조회수·게시 시점·출처를 페르소나의 근거로 보관.
- **타겟 규모 추정**: 실제 시청자 수와 혼동되지 않도록 추정 **범위**와 산정 근거를 함께 표시,
  출처가 부족하면 근거 없는 타겟 규모를 표시하지 않도록 처리(표본 기반 가설로 명시).
  → [[lampas-web-pulse]] "구독자 상한" 정책과 유사한 방향이나 이 세션이 먼저.
- **Copy 4단계 개편**: 분야 선택 → 클립 선택 → 페르소나 선택·추가 → 페르소나별 카피 생성. 클립을
  바꿔도 선택한 분야 페르소나가 유지되도록 처리. 선택한 페르소나로 카피 10개 생성·교차 채점.
- 검증: Copy·Pulse 관련 테스트 56개, Copy 웹 테스트 28개 통과, 두 웹 앱 빌드 성공. 최종 보고 시점
  테스트 87개, 타입 검사·웹 빌드 통과.

## 배포 (사용자 "배포해줘" 요청)
- 운영 DB에 분야별 리서치·페르소나 테이블 추가, 로컬에서 수집한 MLB 영상 20개를 운영에도 반영.
- lampas-api 전체 테스트 928개 통과 후 운영 서버 배포(의존성 설치·재시작). 운영에서 분야 5개·MLB
  영상 20개 정상 조회, 페르소나 조회의 로그인 보호 정상 확인.
- Copy·Pulse 웹 배포·CDN 반영 완료(전체 테스트 967개 통과). 최종 링크:
  `copy.lampas.io/?field=mlb`(분야별 페르소나 선택·카피 생성), `pulse.lampas.io/fields`(MLB 인기
  영상 20개 조회).

## 마지막 질문과 미해결 구조
사용자: "Pulse에서 수집된 건 어디로 가는 거지?" → 어시스턴트 답변으로 **수집 경로가 두 개로
갈라져 있음**이 이 세션 시점에 이미 드러남:
1. 기존 Pulse 수집 → 기존 미션에 저장 → Pulse "수집" 탭에서 확인.
2. 이번에 추가한 분야별 수집 → 별도 리서치 저장소 → `pulse.lampas.io/fields`·Copy "인기 영상과
   출처 보기"에 표시. 페르소나 참고 자료로만 쓰이고 클립 뱅크에 자동 추가되지 않음(카피용 클립은
   기존 클립 뱅크에서 별도 선택).

어시스턴트가 명시: "현재 기존 수집 미션과 새 분야별 리서치를 하나로 연결하지 않아, 어디로 들어가는지
헷갈릴 수 있는 구조입니다." — 이 문제 제기가 같은 날 8시간 뒤 11:14 세션의 "Pulse를 페르소나
단일 출처로, Copy는 선택만"이라는 방향 전환과 **내용상 정확히 맞아떨어진다**(두 경로 통합 필요성).
다만 인과관계(사용자가 이 문제를 근거로 다음 세션에서 재지시했는지)는 소스로 확인되지 않아
추정으로만 기록.
