# 2026-07-15 — 과금 모드(API vs 구독) 토글 + 구독 모드 컨텍스트 잔여 표시

`[[lampas-harness]]` 웹 채팅에 **Claude 인증/과금 모드 토글**과 **구독 모드일 때 컨텍스트
잔여량 표시** 기능을 추가한 코딩 세션. 2026-07-15 01:17~01:40, 약 6왕복.
소스: [[raw/conversations/2026-07-15-과금모드-토글-컨텍스트표시]].

## 발단 — "지금 뭐로 과금되나?"
사용자가 "지금 Claude Code(정액)로 과금되나, SDK로 API 종량 과금되나?"라고 물음.
어시스턴트가 코드/`.env`를 확인해 답:

- **`.env`에 `CLAUDE_CODE_OAUTH_TOKEN`이 설정, `ANTHROPIC_API_KEY`는 주석 처리(비활성)** → **Claude
  Code 구독(정액) 과금**. (01:17 시점 확인)
- `src/server.ts`의 `query()` 호출(~1750줄)은 `apiKey`를 넘기지 않음. Claude Agent SDK는
  `ANTHROPIC_API_KEY`가 없으면 `CLAUDE_CODE_OAUTH_TOKEN`(=`claude login` 구독 인증)을 사용.
- 이 대화 세션 자체도 `CLAUDE_CODE_EXECPATH`가 SDK 번들 `claude` 바이너리를 가리키는 걸로 봐 같은 경로.
- `ANTHROPIC_API_KEY`는 현재 **모델 목록 조회(`claudeModelsLive()`, `server.ts:599`)에만** 쓰이고
  실제 대화 실행엔 무관.

> ⚠️ **모순/모호**: 위 첫 확인(01:17)은 "API 키 주석 처리(비활성)"라 했는데, 세션 마지막(01:40)엔
> "`.env`에 `ANTHROPIC_API_KEY`가 이미 설정돼 있어서(주석 해제된 상태) 체크박스가 기본 활성으로 뜬다"고
> 상반되게 말함. 또 기존 위키([[lampas-harness]] 인증 줄, 2026-07-06~07 시점)는 "`ANTHROPIC_API_KEY`
> 직접 키(구독 로그인 아님)"라고 기록. → **하네스가 기본으로 구독(OAuth) 인증을 쓴다는 것은 이 세션의
> 코드 근거로 확실하나, `.env`의 API 키 주석 상태는 세션 내에서도 엇갈려 재확인 필요.** 아마 도중에
> 주석을 해제했거나, 두 진술 중 하나가 부정확.

## 사용자 요청 (구현 대상)
Claude 모델을 골랐고 API 과금이 아닌 상태일 때:
1. "API 사용" 체크박스를 추가해 Claude Code 모드 / API 모드를 선택 가능하게.
2. 구독(Claude Code) 모드에서는 컨텍스트 표시를 **과금액이 아니라 컨텍스트 잔여량**으로 —
   "컨텍스트"를 누르면 지금 얼마나 남았는지 보이게.

## 조사 결과 (구현 지점)
백그라운드 조사 에이전트가 항목별로 정리:
1. **모델 판별**: `src/server.ts:653` `isClaudeModel(model)` = `startsWith("claude-")`. `runChatTurn`(2617)이
   image→claude→local→google→openai 순 분기.
2. **`query()` 옵션에 `apiKey`/`env` 미설정** — 서브프로세스가 `process.env`를 그대로 상속. SDK
   `Options` 타입(`sdk.d.ts:1278`)엔 **`apiKey` 필드 없음**, `env?`(1407)만 있고 설정 시 서브프로세스 env를
   **통째로 교체(병합 아님)**. → 토글은 `options.env`로 원치 않는 자격증명 변수를 빼서 인증 방식 강제.
3. **모드 식별용**: init 메시지(`SDKSystemMessage`, `sdk.d.ts:4141`)에 `apiKeySource`
   (`'user'|'project'|'org'|'temporary'|'oauth'`) 필드 존재 — 기존 코드(`server.ts:1798`)는 버리고 있었음.
4. **SDK 컨텍스트/한도 API**: `Query.getContextUsage()`(`sdk.d.ts:2369`) → `totalTokens/maxTokens/percentage/
   categories/gridRows`. `Query.usage_EXPERIMENTAL...()`(2383) → `session.total_cost_usd`,
   `subscription_type`(`'pro'|'max'|'team'|'enterprise'|null`), `rate_limits.five_hour/seven_day`(claude.ai
   구독 5시간/7일 한도). API 키 세션은 `rate_limits_available: false`.
5. **과금/토큰 표시 이미 상당 부분 구현**: `result` 메시지의 `usage`/`total_cost_usd`를 `recordUsage()`로
   누적, 프론트 `◔ 컨텍스트` 버튼→`/api/usage`→`renderUsageModal`이 입력/출력/총토큰/비용($) 테이블 렌더.
   단 **API/OAuth 구분 없이 항상 비용($)만** 표시 → 여기 분기 필요.

## 구현 (완료)
`src/server.ts`
- `TurnOpts.apiBilling?: boolean` 추가, `/api/chat`에서 파싱.
- **`claudeAuthEnv()` 헬퍼 신설** — 체크박스 상태에 따라 서브프로세스 env에서 `ANTHROPIC_API_KEY` 또는
  `CLAUDE_CODE_OAUTH_TOKEN` 중 원치 않는 쪽을 지워 넘김. API 모드인데 키 없으면 에러 후 중단.
- init 메시지의 `apiKeySource`, `stream.getContextUsage()`(컨텍스트 사용률)를 캡처해 `UsageTotals`에
  `billingMode`/`contextWindow`로 저장.
- `/api/models` 응답에 `anthropicApiKeyConfigured: !!process.env.ANTHROPIC_API_KEY` 노출(체크박스 활성 가능 여부).

`apps/web/index.html`
- 입력창 하단에 "API 사용" 체크박스 — **Claude 모델 선택 시에만** 표시, 키 없으면 비활성(안내 툴팁).
- 상태 `localStorage` 저장, `/api/chat` 요청에 실려감.
- 컨텍스트 모달: `billingMode === 'oauth'`(구독)일 때 "예상 비용" 대신 **"컨텍스트 잔여 %(잔여 토큰)"** 표시.
  API 모드면 기존대로 비용($) 표시.

타입체크(`tsc --noEmit`)와 인라인 스크립트 구문 검사 통과.

## 운영/함정
- **"Stream closed" 재발** — 세션 중반 파일 쓰기 도구(Edit/Bash write)가 전부 "Stream closed"로 실패,
  읽기 전용 명령은 정상. 브라우저 채팅 탭 새로고침 요청 → 이후 정상 복구해 구현 완료.
  → [[self-hosted-agent-server-ops]]
- **재시작은 사용자 몫** — 8787 서버가 옛 코드로 떠 있어 반영엔 재시작 필요하나, 어시스턴트가 자기 턴에서
  죽이면 응답 채널이 끊김 → 사용자가 launchd 재기동. → [[self-hosted-agent-server-ops]]

## 결정/사실
- **하네스 기본 과금 = Claude Code 구독(OAuth)** (코드 근거 확실; `.env` API 키 주석 상태는 재확인 필요).
- Claude Agent SDK엔 `apiKey` 옵션이 없다 — **인증 전환은 `options.env`에서 자격증명 변수 존재 여부로 제어**.
  → 스킬: [[sdk-claude-code-vs-api-billing]]
- 구독 모드 컨텍스트 잔여율은 `stream.getContextUsage()`, 5시간/7일 한도는 `usage_EXPERIMENTAL...()`로 얻는다.
