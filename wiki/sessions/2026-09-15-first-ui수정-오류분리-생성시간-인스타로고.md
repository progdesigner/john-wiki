## 진행 순서

1. **깨지는 UI 수정** — 스크린샷 첨부, "깨지는 UI 개선해줘". 원인: `/create` 페이지의 **영상 비율
   선택용 라디오 버튼에 일반 입력창(input) 스타일이 잘못 적용**돼 버튼이 늘어나고 라벨 글자와
   겹침. 스타일 적용 범위를 좁혀 좁은 화면에서도 선택 항목이 영역 안에 들어오도록 수정.
2. **배포** — "개선되면 배포해줘". 모바일·데스크톱 4개 화면 너비에서 겹침·가로 넘침 없음, 키보드
   선택, 빌드 통과 확인 후 지정 배포 스크립트로 `first.dalar.ai/create`에 반영.
3. **주문 오류 표시 사용자/관리자 분리** — 특정 주문 URL(`/orders/<id>`) 링크와 함께 "여기서는
   오류가 사용자 친화적으로 보이게, admin 에서는 자세히 보여줘" 요청.
   - **고객 화면**: 자동 재시도 중엔 "잠시 지연되어 다시 시도하고 있어요", 제작이 완전히 중단된
     경우엔 고객센터 연결 안내로 교체 — 오류 원문은 노출하지 않음.
   - **관리자 화면**: 주문 상태·실패 단계·재시도 횟수·오류 원문을 함께 표시.
   - 절차를 스킬로 정리 → [[user-facing-error-admin-detail-split]].
   - 테스트 데이터로 두 화면 검증 후 배포·운영 반영 확인.
4. **관리자 총 생성 시간 표시** — "어드민에서는 총 생성 시간도 알 수 있게 해서 배포해줘", 이어서
   "배포되면 커밋 후 푸시 해줘"로 커밋 범위까지 지정.
   - 기존 저장된 **결제 시각 ~ 최종 영상 제공 시각**을 기준으로 계산, 대기·재시도 시간도 포함됨을
     관리자 화면에 명시.
   - **완료 주문**은 총 소요 시간을 고정 표시, **제작 중인 주문**은 매초 갱신.
   - 완료·구매 확정·중단·미결제 상태 전부와, 고객 화면엔 노출되지 않음을 검증.
   - 커밋 범위는 "First 프론트 앱 전체 + 이번 수정"으로 사용자가 직접 지정 → 커밋 `12691a01` →
     `origin/main` 푸시.
5. **관리자 영상 미리보기 이미지** — 스크린샷 첨부, "어드민에 영상의 이미지가 보이게 해줘".
   - 원인: 장면(scene) 영상에 미리보기(poster) 이미지가 지정되지 않아 재생 전엔 검은 화면.
   - 수정: 각 장면의 **생성 이미지를 영상 미리보기로 연결**. 이미지가 아직 없는 장면은 영상 정보를
     미리 불러오도록 보강.
   - 이미지 로딩·영상 재생 확인 후 배포·커밋·푸시: 커밋 `fa3ee1ee`.
6. **Instagram 프로필 로고 제작 + S3 업로드 + f/i 점 정렬 수정** — 별도 요청 3턴:
   - "이 First 로고를 인스타그램 프로필 사진으로 올릴 수 있게 이미지를 만들어줘, 경로를 달라" →
     기존 `first` 워드마크 서체를 유지, 브랜드 브라운 배경 + 밝은 크림 로고, 원형 크롭에도 여백이
     남도록 **1080×1080 PNG**로 제작(`image_gen` 스킬 사용). 로컬 경로 제공:
     `output/first-brand/first-instagram-profile-1080.png`.
   - "S3 에 올려서 경로를 달라고" → First 사이트 공개 경로에 추가 후 지정 배포 스크립트로 S3 업로드,
     공개 URL 제공: `https://first.dalar.ai/brand/first-instagram-profile-1080.png`.
   - "F의 동그란 포인트 부분과 I의 동그란 포인트 부분이 완전 겹치게 다시 수정해주고 웹상의 로고도
     수정해줘" → `f`의 둥근 끝을 `i`의 점으로 함께 쓰는 형태로 **같은 벡터 원본을 프로필 이미지와
     웹 상·하단 로고 양쪽에 동일 적용**해 모양을 일치시킴. 모바일·데스크톱 표시·빌드 확인 후 배포.
     신규 URL: `https://first.dalar.ai/brand/first-instagram-profile-1080-v2.png`(기존 v1 URL도 유지).
